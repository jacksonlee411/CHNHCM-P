# 评审 CHNHCM-P 变更

从当前工作树的[项目约定](../../../AGENTS.md)和[文档登记表](../../../docs/governance/registry.json)找到对象合同与本次交接。确认受评提交或工作区差异，连同相关未跟踪文件一起核对。区分计划状态、实际实现和受测版本。

沿经办或只读角色的正常入口核对行为。领域事实检查 Go 所有者、持久化和调用方；更正、撤销或迁移检查原修订、原采用、回执和当前权限能否按原身份查回。[历史保留合同](../../../docs/adr/025-greenfield-implementation-policy.md)

页面差异与同一构建的参考页比较，按[共享交互规范](../../../docs/specs/m02/012-m02-functional-and-interaction-design.md)检查可操作字段、日期、取消和返回上下文。验收环境、数据和既有工作区修改按项目约定保护。

报告能触发问题的角色、输入、行为、影响和文件位置。复审把原问题逐项对到当前改动与证据。若未发现问题，写明检查的版本、路径及尚未验证的范围。
