### 4.1 R02 搜索草稿与查询状态转换

正式状态表由 [012 搜索草稿与已应用条件](../../specs/m02/012-m02-functional-and-interaction-design.md#m02-ui-query-state)唯一维护：草稿只在列表内存中存在，分页/重试保留，筛选动作应用整组条件，离开/返回及浏览器历史导航按目标 URL 重建，迟到响应不能覆盖新输入。

T03 至少验证下列第 1—4 项，记录输入框、URL、实际请求和提示；T04 接入名称链接后执行第 5 项。T02 只建立失败基线，不能把事件表写入文档记为这些场景已通过：

1. 应用“青禾”并到第 2 页，输入尚未应用的“研发”，翻页或改页大小仍请求“青禾”且保留“研发”；随后切换状态为启用，整组条件改为“研发＋启用”并回第 1 页。
2. 应用“青禾”后输入“研发”，打开已有结果的详情，再分别用返回列表和浏览器后退进入列表，输入框恢复为目标 URL 的“青禾”；刷新及前进到另一查询地址也分别以各自 URL 重建。
3. 发起“青禾”查询后输入“研发”，让前次响应成功或失败，输入仍为“研发”；重试失败请求仍查询“青禾”。较早请求晚于新请求返回时不能覆盖当前结果。
4. 清空输入后先翻页，仍使用原已应用关键词；点击查询后才移除 `q` 并回第 1 页。当前授权失效时清空草稿与受限结果，网络失败仍保留草稿供恢复。
5. T04 新标签打开名称链接时，原标签未应用输入不变，新标签返回列表按其合法 URL 初始化，不继承该草稿。

#### 7.1.1 视口与真实缩放矩阵

本批完整矩阵及缩放方法由 [012 视口与真实页面缩放](../../specs/m02/012-m02-functional-and-interaction-design.md#m02-ui-viewport-matrix)持有：1440×900、1440×540、390×844、320×900、320×256 的 100% 视口，以及固定外框的真实 200%/400%。这些条件全部属于 T03/T04 必验范围，不得将压力视口、CSS 缩放或捏合冒充真实浏览器缩放。

T02 已在 Xvfb 独立显示环境通过原生快捷键采集 200%/400%：100% 内容 1280×900，外框 1280×1039 固定，放大后分别 640×450 和 320×225；原生倍率截图和恢复 100% 的测量保存在基线报告。400% 列表零高是失败基线，不因成功设置倍率而记为页面通过。

后续评审发现首次 12 张缩放页面图仅覆盖左上区域，完整图面证据改用[补验记录](../../verification/100-ui-baseline-capture-fix.md)。补采采用同一产品基线及原生倍率，全部输出 1280×900 像素；上述 CSS 尺寸和 DOM 结论保持，不把截图工具修复算作产品问题关闭。

#### 7.1.2 操作、预期与结果登记

每个矩阵条件至少覆盖登录、列表、创建、详情/日志及历史返回。使用虚构数据，分别从正常菜单操作；以实际滚轮、Tab/Shift+Tab、Enter/Escape 核对下列结果，截图只作辅助：

1. 登录名、密码、登录按钮和失败提示可达；列表可完成搜索、筛选、翻页和打开对象详情。T03 可使用既有名称按钮，T04 后须验证名称链接。正文具有可用阅读区域或可通过正常文档滚动到达，不出现固定控制区覆盖内容、焦点不可见或页面必须双向滚动才能完成办理。
2. 创建表单全部有权可见字段、就地错误、保存/取消和未保存确认按钮可达，放大后不丢失输入；成功/拒绝/未知提交的含义与服务端事实一致。
3. 详情、日期和日志可完整读取，历史标识与返回当前资料入口可辨且可操作；切换页签、查看确切来源、退出历史和返回列表后，模式、条件及焦点正确。

T03 在这些条件下验证当批 R01—R04 及既有创建/查询行为；名称仍为按钮时保留原返回焦点检查，不要求 T04 的链接改造或历史常驻布局提前完成。T04 接入 R05—R09 后，必须执行第 4.2 节的名称链接返回验收，并按实际影响补跑矩阵条件；这两批的完成证据分别记录，最终交付不能只保留改造前的结果。

200% 与 400% 必须分别记录 `passed/failed/interrupted/not_run`，不能合并为“缩放检查通过”。缺少有界面浏览器、无法设置或核实真实倍率、缺少任一必要页面操作时如实记录对应未覆盖结果；实际缩放或其他矩阵条件存在失败、中断、未运行时，R01 的相关验收和 T03 的完成判定保持未关闭，T06 不得关闭整个计划。后续 T04/T05 改动影响这些布局或交互时补验受影响条件，不能沿用失效的旧结果。

文字对比度与重排核对参考 W3C 的 WCAG 2.2 [SC 1.4.3 说明](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)和[SC 1.4.10 说明](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html)，核对日期为 2026-11-01。普通文字以 4.5:1 为最低目标；按实际前景、透明叠加后的背景及交互状态测量。320×256 是本项目组合压力用例，并非标准要求所有页面同时使用这组宽高；这些局部检查不等于完整 WCAG 合规声明。

多节点时间轴、空集合和长日志可用公共组件夹具辅助验证布局。真实业务结果须核对页面与实际持久事实；新增/更正/删除/停用未接线时仍归 010，不从夹具、旧来源测试或截图推导业务完成。
