# CHNHCM-029 X03 授权页面优化方案

本方案供客户安全管理员、产品、Access 和客户 Web 维护者评审。目标是让管理员从「设置 → 安全管理 → 授权」找准一个人、看懂他持有的每一份授予、办对一笔变更，再从历史说明当时改了什么。现行判权和历史规则由 [028 客户管理员合同](../../specs/x03/028-local-account-and-authorization.md)持有。文稿状态与执行进度见[文档登记](../../governance/registry.json)。

## 2 从两个入口查同一份授予

**从账号进入是主路径。** 管理员打开「授权」，用登录名或显示名找人。默认控制区是一行标题、更多操作、搜索和分页。列表显示「账号」「管理归属」「账号状态」，有业务授予读取范围时再显示「生效授予（可见）」。账号主行用显示名，副行用登录名，缺显示名时直接用登录名。有权获知的零份显示 0，尚未加载显示加载态，读取失败保留条件并提供重试。停用账号仍能在有权时查原授予，任何数量都只统计该管理员可见的授予。登录仍需核验账号状态和凭据，具体业务能否办理由 Go 在业务请求时判定。业务选择器继续只返回办理所需的身份。新增计数的适用面限于授权管理列表，实施时须单列修订 028 的读取合同。[管理范围与选择](../../specs/x03/028-local-account-and-authorization.md#x03-br-003)

**从角色或策略进入是反查路径。** 在某个已发布版本点「查看引用此版本的授予」，按该**确切版本**列出获准的账号、角色、范围、来源、有效期和状态。一行打开同一份授权明细，返回时恢复版本、条件和焦点。相邻版本独立查询。有发布权但无权查看账号的人只能查看获准版本资料。账号详情现有「查看账号授权」也进入同一授权页，其返回入口写明「返回账号资料」。其他安全管理菜单保留各自职责，角色发布整页的改版另行安排。

**查询规则沿用业务单元。** 状态、来源、管理归属等适用条件从对应列菜单进入，显示已应用条件。输入关键词再应用筛选时两者一次生效，取消筛选保留输入，更改页大小仅更改分页。列表链接携带已应用条件，直接打开链接时重新授权。返回时恢复页码、滚动位置和原行焦点。保留现有授权详情及指向指定授予的链接。直接打开可见授予时定位该份，无合法来源时返回授权账号列表。原行已失权则清除受限内容，聚焦仍可见的栏目标题。[共享查询规范](../../specs/m02/012-m02-functional-and-interaction-design.md#m02-ui-query-state) · [链接与返回](../../specs/m02/012-m02-functional-and-interaction-design.md#m02-ui-link-return) · [同构建参考页控制区](../../../apps/web/src/features/organization/BusinessUnitListControls.tsx)

## 4 管理员怎样办完一件事

新增和换版沿用共享表单。桌面左列「授予内容」放角色、目标和字段，右列「来源与期限」放本职或代理及起止时刻，换版时右列展示这份授予已确定的来源和期限。短屏和放大时可按组单列阅读。打开表单即能看到账号、办理动作及可编辑字段，选定角色后的动作按业务入口可查。授权按钮和取消沿用顶部控制区，使用同一份草稿。[共享表单规范](../../specs/m02/012-m02-functional-and-interaction-design.md#m02-ui-object-form) · [共用表单](../../../packages/ui/src/components/ObjectForm.tsx)

## 5 实施顺序与责任

| 顺序 | 交付物及责任 | 进入下一步的判据 |
| --- | --- | --- |
| 一　撤销与日志 | Access 与 Web 先接通一份授予的身份和修订、每份授予的可办动作、撤销表单、键盘返回及该份日志。现有事件含目标和请求标识。按其定位当次授予或委派修订，补齐当时的目标、版本和可见差异。 | 相同角色的本职与代理在提交前能区分，取消回到原行，提交后可从日志回到准确目标。 |
| 二　授权目录与详情 | Access 在现行管理读合同增加授权列表专用的可见摘要、账号内逐份搜索与有界分页、稳定定位。账号、授予和事件各自按获权全集查询及计数，分页与逐行摘要共享服务端查询条件。Web 接入公共控制区、表格、页签、表单及来源返回。 | 183 份量级下按账号、角色、范围、来源可定位，无需整页传输或逐行补查。内置管理员资格在短屏首屏可见。 |

## 7 评审决定与实施核对

2026-11-28 对当前管理查询、回执查回、授权修订和共享版本停用事务逐项复核。评审采用以下边界。

- **浏览与办理分开读取。** 正常浏览只传当前可见页及所用版本。版本筛选候选在打开筛选时读取，输入草稿时再读取可用策略。复用共享控制区、列菜单、分页、详情和表单。账号状态和管理归属共用一个筛选框。授予明细用一个入口同时设置来源、版本和状态。授予表采用原生语义表格，桌面放大后每份自动按字段排列。
- **只保存已有事实。** 日志用管理回执的请求身份关联当次和上次授予修订。重新读取时按当前权限裁剪历史。服务端按完整委派上限逐份决定读写和换版能力。回执查回按请求身份定位，与浏览页码独立。
- **停用使用一次正常提交。** 影响摘要覆盖当前生效、待生效的业务授予和有效管理职责。用原版本锁在同一事务核对引用集合。只有可完整办理时才返回核对标记，引用变化时在原表单重读。沿用现有命令、表和回执。
