## 1 用户目标

管理员和查询者从“设置→组织配置→部门”进入，通过左侧部门树找到组织分支，在右侧现有列表查询本部门或本部门及下级，按原入口查看详情、维护记录、选择和导出。页面视觉对齐CubeBox，部门关系、日期和权限仍由本仓Go内核决定。

前置条件是当前会话具有部门读取权；树额外消费现有名称、状态、行政上级、路径及最小引用读权，不因角色名称直接放权。维护、历史和导出仍分别授权。树提供查询范围，修改组织关系继续从详情办理。

2026-11-13用户要求据已提出的建议制定实施方案，随后要求评审和完善。原评审批交付为修订后的计划及主代理文档评审；用户随后已授权实施，当前开工进展见文末实施记录。第2—6节是本任务的实施设计，T00须同步长期规格、具体DTO和错误映射；文档评审不表示人工业务验收、开工授权或现行产品已经切换合同。

### 3.2 Go和存储实现

新增能力由Organization应用层的部门查询服务拥有，复用当前部门／层级事实、有效期解析和X03读取计划。SQL提供必要的窄事实和候选，Go决定有效父边、可达范围、权限及匹配。可以增加经证明必要的索引或查询投影，但不得在前端复制业务日历、用路径字符串前缀判定子树，或把当前结构与历史路径混用。

根／子节点查询只准备本页和必要依赖；hasChildren采用批量必要事实读取，避免每节点另发HTTP或完整详情请求。稀疏授权下证明没有下一项／可见子项可能扫描较多候选，须计入T01成本，不能承诺恒定一页扫描。名称、关系与授权事实须满足132单请求一致捕获合同，不能先读ID再拼接另一时刻的名称或父边。正常分页不跨HTTP持事务，取消应传到数据库读取。

子树列表的准确总数和全选完整身份捕获可能必须遍历整个相关子树，不能承诺其成本只与页大小有关。优先遍历必要身份和父边；结构遍历不得先按可显示对象剪断中间节点，候选投影与计数再执行当前授权。普通页只为本页及条件判定所需对象装配必要资料和路径，不恢复全企业宽投影。T01必须测量宽根、深链、零匹配、仅引用中间节点、全子树计数和身份捕获的真实成本，再冻结查询形状。

默认先复用当前模型和读取段，不预建闭包表、永久树缓存或整树版本。若T01证明必须改表或加派生数据，先记录唯一写入者、当前和未来生效、改上级／改BU／更正／删除／改日的原子更新、完整性损坏拒绝、重启恢复及写放大；按005/134协调模型和全仓迁移编号。不得用删除历史或放松完整性换取读取指标。

### 3.3 前端接入和状态归属

共用ObjectList增加可选侧栏位置和对象查询扩展；部门由departmentAdapter接入，BU没有树入口和树范围参数。共用SelectionQuery如需拆分为对象专属类型，应同步适配器及生成客户端，不给BU保留无消费者的字段。

| 状态 | 归属与生命周期 |
| --- | --- |
| 已应用部门范围、右侧条件／排序／页码 | 安全路由查询；参与规范化请求键和返回上下文 |
| 展开节点、树滚动、侧栏开关 | 当前会话的页面返回状态，仅保存必要身份和位置；不将名称、权限或整树存入浏览器持久缓存 |
| 树定位输入、候选及同级窗口 | 独立读取状态与取消控制；切换模式、会话／日期变化或失权时失效 |
| 批量选择 | 复用133固定身份草稿；本人已核验草稿状态与当前页可用性分开，不以树展开结果计算成员或已选数量 |
| 详情表单与未确认提交 | 保留现有机制，不由树的辅助刷新重挂组件或清空用户输入 |

当前DatedPages.tsx以完整URL参数构造queryKey，并在patch中处理搜索草稿和选择失效。接入时须区分业务查询、分页和纯树展示事件，先比较规范化查询再失效，避免无效点击、展开节点触发列表重查或无意应用搜索草稿。返回重新取得当前获权标签，不能用旧历史状态回填名称。

2026-11-14用户明确保留筛选交集，并反馈搜索框已清空仍沿用旧关键词。本次由d在dfc4ba17基线上修复部门清空关键词立即重查及树切换结束旧详情定位；非空草稿与其他筛选保持。受影响消费者为部门列表，共用ObjectList保留BU原行为；012／118／119、回归及300报告同批更新，无API／模型／迁移变化，集成时同步本合同。原“切换树节点清除全部筛选”候选已撤回，未更新手工环境。

同日用户继续指出旧对象不在结果的常驻提示无必要，本轮删除共用列表的该提示及其“查看原对象”入口；BU和部门统一直接呈现当前查询结果，返回缺失目标时使用已有列表标题焦点回退。实际读取错误和重试仍独立显示。d负责同步012／119、三个受影响返回用例及300记录，无API／模型／迁移变化，保留前批搜索修复与证据。

现有useQuerySelection在读取失败时clear，并要求data存在才认定valid和允许导出；必须与第3.1节的部门响应同时改造，不能只改提示文案。草稿有效性由会话、D、queryKey和已确认revision决定；范围页缺失时仍可据summary操作导出，文件名回退来自已核验业务日，不依赖缺失page。仅辅助读取失败的待核验状态与草稿真正失效使用不同分支；BU回归覆盖原有取消、选择和导出。

定位链先显示目标，按需补齐获权同级窗口；同时在途树请求最多2个，切换目标取消旧请求。非当前定位链的节点缓存初始上限2000项、分支页40页、展开身份2000项，先达到者触发淘汰；非焦点分支可收起后重读，不能隐藏服务端后续结果。定位链单独持有一条，空间随实际深度h增长为O(h)，不宣称任意深度均为常数内存；旧链随新链替换释放。可见窗口含预留行的树行DOM最多200个，焦点／目标在虚拟窗口中可达。T01/T03记录节点、深度、响应字节、DOM、请求量和峰值内存；预算若需调整先记录测量和替代数值，不以硬截断业务层级达标。必要长链超出请求预算时明确失败、可重试，不返回半条成功路径。
