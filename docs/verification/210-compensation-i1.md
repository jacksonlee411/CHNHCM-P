## 3 评审发现与复验

第一轮按保存和读取分别核对。切换定额与薪带可能清除原有受限金额，已在写入事务中核验原形式的金额字段权限。只读账号与只收窄单一金额字段的管理员分别验证。日期维护窗口改由服务端返回，前端提交发生变化的字段。

第二轮核对历史与周边回归。新增及启停的原依据和结果分别关联准确记录及修订，来源页与当期详情分别按权读取。新增浏览器场景首次未登记到 CI 影响集，造成四条范围检查失败，补齐消费关系后 189 项检查通过。

旧迁移演练最初只排除 00058，因引入 00059 后错误地将新迁移放进 00057 前缀而失败。演练已改为按真实的 00057 上界建库。在同一 PostgreSQL 用例中复验了历史完整前缀升级、幽灵版本、迁移中断及实际数据。确切版本录入检查和真实 00038、00039、00057 授予迁移均通过。

第三轮覆盖源职级先更名、再出现三月停用缺口。旧薪标及旧回执可按现权读取。更正后新的薪标引用更名版本，三月缺口将整笔依赖写入拒绝。三项 [DB/API 场景](../../internal/bootstrap/compensation_grade_rate_integration_test.go) 和金额精度[独立断言](../../internal/contexts/compensation/domain/rate_test.go)已复验。首次浏览器前置创建职级时缺浏览器来源而收到 403，修正会话请求后正常建档。随后历史断言过早在日志中匹配到了两处相同金额，改为先等只读原件出现再验证其上限字段。原生 200% 正常保存及并发冲突保留输入、丢失响应查回均已实测。

第四轮分别验证同一管理员只获部分金额字段以及分属两份不完整授予的情形。切换定额或薪带时，在同一份授权中校验明示变更和隐含清除，两个反例均整笔拒绝。针对 409 再次读取后，管理员输入的上限和他人已保存的下限可同时保留；丢失成功响应后按原提交号找回并且日志只增加一笔。[DB/API 反例](../../internal/bootstrap/compensation_grade_rate_integration_test.go) · [真实浏览器流程](../../tests/e2e/compensation210.spec.ts)

## 4 手工验收环境

公共仓 wt-dev-c 新建并保留 `m09-compensation-c`，Web 4521、API 8521、DB 54521。使用项目本地管理员或查询账号登录[实际薪标菜单](http://127.0.0.1:4521/settings/compensation/grade-rates)。本环境以 X03 的版本绑定明确授予这两个账号所需的薪标和职级权限。已有绑定和撤销记录均按原状态保留。

管理员已用正常菜单录入 [P5 月标](http://127.0.0.1:4521/settings/compensation/grade-rates/8ccc6f29-9980-4ae1-bb13-971d5ee572e8) 和 [P5 年标](http://127.0.0.1:4521/settings/compensation/grade-rates/1a9fc2f1-7f13-4cb8-a89b-720890fd311d)。月标含 2027-01-01 与 2027-07-01 两段，年标自 2027-01-01 为 180,000.00 元。查询账号能读两项，列表没有新建入口。更新固定构建前保留了匹配的 API、页面和数据库转储，之后从同一地址查回两份标准。工作树维护者在下次更新或用户验收结束时复查。

同一固定构建对照了 M03 职级详情和 M09 薪标详情。1440×900 时正文从 128、129 CSS 像素处开始，1440×540 时从 129、130 处开始。桌面正文可独立滚动，短屏按共享规则随文档滚动。两种视口下均验证 Enter 打开更多操作、Escape 返回触发按钮、Tab 和 Shift+Tab 在连续金额输入间往返、键盘返回保存按钮，以及取消退出。首次对照脚本误将桌面独立滚动的断言用于短屏，按[共享视口合同](../specs/m02/012-m02-functional-and-interaction-design.md#m02-ui-viewport-matrix)分别复测通过。

## 5 阶段结论与边界

I1 的管理员正常菜单、定额和连续薪带、按日调整、更正与撤去、原版追溯、当前权限与失联查回均有实测结果。独立 Chromium 固定构建的 4 项场景全部通过。1440×900 与 1440×540 均走完新建、未来调整、取消、更正前原件、撤去并回列表。原生 200% 按浏览器实际倍率和 640×450 CSS 视口核验。第四轮复验后，本阶段已测合同内没有新增主要问题。[浏览器用例](../../tests/e2e/compensation210.spec.ts)

`make check` 已通过，覆盖 189 项文档工具检查、仓库链接和登记、Go 分层及 SQL 归属、Go 单测、静态检查与前端类型检查。登记核对时修正了实际菜单路径的来源文件。实库回归分别针对薪标、旧迁移升级和中断恢复。浏览器临时环境及其数据已回收，4521 保留用于人工验收。[职级薪标接入范围](../architecture/contexts.json)

共享标准被计划采用后如何调价、停用的跨计划影响及原采用由 I2 实施。两类对象的容量和两套完整制度联验归 I3。当前样例均为合成制度，业务经办人的正式签收另行记录。
