## 3 终稿反例走查

| 评审输入 | 对照结果及依据 |
| --- | --- |
| 只凭姓名建档，证件换新或到期，只有办理权的经办人不能补核 | 原人原号保留。获权核对人更新 M01，按新来源核回到岗日，放弃后续入职只放弃 M04 草稿。不能由看到档案推得明文权限。[身份及补证](../specs/m04/401-direct-hire-requirements.md#m04-ac-001) |
| 拟任 2027-04-01 至 2027-05-31，A 只合格到 2027-04-30，B 仅有接收用途 | 拟任 61 天，A 缺后 31 天，B 的用途不能填补 A 的用人角色。若入职先行，后续拟议收窄检查在用安排。旧采用仍可解释。[L2 与 L3](../specs/m04/403-hire-technical-contract.md#hire-ports) |
| 上半段仅按职务，下半段按岗位，或同一岗位前免占后占。所余最后一编被另一人取得 | 跨模式使用不同子段输入，均以同一事务判断。满编的后段使拟议入职整笔失败，两人的 M01 档案独立保留。免占编新增遇暂停也被拒。[分段与原子提交](../specs/m04/403-hire-technical-contract.md#hire-transaction) |
| A、B 两份关系中主关系 B 受限，另有政策在将来的日期由可选改必选 | 各适用员工关系均选自己的主任职，部分可见结果不能重选真实主目标。必需覆盖有空洞时新政策无法激活，同期入职受同一版本守卫约束。[主选择样本](../specs/m04/401-direct-hire-requirements.md#m04-ac-009) |
| 同日调部门、晋升，后项分别为独立与依赖。撤销或更正前项再查旧来源 | 独立调动保留。必要依赖须重验和明确处置，保留的后项在新来源引用准确修订。旧来源按旧修订解释。各次更正不会多计一次晋升。[动作与后继](../specs/m04/403-hire-technical-contract.md#hire-actions) |
| 同一单据行换经办人或提交号、换人、撤销后再重送。查回先于迟到写入 | 合法重送只定位同一业务办理，另一人仅按自己当前授权读取。换人与原绑定冲突，另一真实行可独立办理。已确认未执行的提交号封闭，撤销后的旧成功请求不重建任职。[业务键与回执](../specs/m04/403-hire-technical-contract.md#hire-recovery) |

日期复算使用标准库独立枚举日历日。程序核实 61 天由 30 和 31 天两段组成、资格缺段起点、证件到期日包含关系、换版当日占编数、两个 30 天区间重叠 15 天后并集为 45 天。该复算用于校验文档输入和预期。[可复跑算例](https://github.com/jacksonlee411/CHNHCM/blob/061d28105966bd10eb1e3b0032cf2976a6448de4/docs/verification/data/400-hire-readiness/period_examples.py)
