# CHNHCM-313 编制管理合同调整评审

## 1 决定与建议

2026-11-20，依据用户明确的产品方向，现行合同改用“编制管理”，以整数名额核编、预留及占编，有权者直接办理。上一版正文可从 `c5fc24d41524b48cb70f9ca3af2301afd8ac534e` 的同一路径回查。两份旧评审、原始算例和归档输入继续记录各自的历史结论。[现行 313](../specs/m03/313-position-capacity-contract.md) · [上一版评审](313-position-capacity-localization-review.md) · [首版评审](313-position-capacity-contract-review.md)

| 事项 | 调整内容与理由 |
| --- | --- |
| 计量 | 撤去旧版 FTE 限额、工时折算、跨周期基准、四位小数、工时来源跨岗分配与并发守卫。每份任职只需确定是否占 1 个名额。考勤继续使用真实工时，工资继续使用适用于任职的约定金额、小时单价及相应日历 |
| 编制与人员 | 核定编制、已占编制、招聘预留、空编和可用编制各有口径。部门间兼岗可能形成 2 份任职、占 1 或 2 个名额，单位人数按人员身份去重 |
| 直接办理 | 核编、增减编、暂停补员由有权管理员直接保存。招聘使用真实需求版本，人事使用真实任职和任命依据。提交时校验权限、生效期间、可用编制并记录原因。无需发起流程、指定审批人或取得审批单号 |
| 计划与执行 | 人员编制计划保留期间目标与预算的职责。已有计划可关联采用版本，直接核编也有完整日期、原因和操作者。首批验收先完成核编资料，后续接入预留与占编再对账 |
| 归属粒度 | 首批建议沿用岗位核编、按业务日归属部门汇总。若目标客户直接给组织共享总编，建议优先立项组织核编，每次使用选定唯一归属，补齐并发占最后一编、组织内调岗和跨组织调剂的业务验收。首批仅有岗位汇总时，页面不标成部门已核定总编 |

## 2 大陆实践的适用范围

北森披露的一家城市更新集团只给二级组织控编，年度定编、季度复核，组内岗位有使用弹性。金蝶云星空的组织管理指引列出按部门、按职位和按部门加职位编制的做法。两者说明控编层级需要客户业务依据。对于两个岗位都可使用的最后 1 编，简单相加各岗位额度无法在两笔并发招聘之间作出唯一分配。首批建议依赖已交付的岗位和部门身份，组织共用名额作为另一个有明确验收出口的选择。[北森集团案例](https://www.beisen.com/res/1146.html) · [金蝶组织管理指引](https://vip.kingdee.com/article/804364195302499584)

厦门港务发展股份有限公司的《人力资源管理基本制度》第八、九、十八条分别说明年度人员需求、招聘决定和工资总额预算。该制度适用于其本部及相应成员企业，用来区分人员计划、办理和金额。企业自身的治理程序不能推导出本产品必须设置线上审批。这里讨论企业内部定编，机关事业单位的实名入编另有适用制度。以上公开材料于 2026-11-19 至 2026-11-20 核对。[厦门港务公开制度](https://static.cninfo.com.cn/finalpage/2026-02-10/1224973569.PDF) · [事业单位岗位设置管理试行办法](https://rsj.sh.gov.cn/trlzyhshbzbgz_17256/20200617/t0035_1388380.html)

## 3 受影响合同及业务复核

M03 使用岗位编制（StaffingQuota）记录核定名额和使用，M05 拥有招聘需求，M04 拥有工作关系、任职和主选择。正式兼岗按任命用途确定是否另占编。M09 下发该任职的约定金额或小时单价，M10 只做适用的频率换算与期间分摊，X06 对人数、任职和已占编制分别取数。模块编辑源、术语、图面和 [313 本地修订链](../reference/local-revisions.json) 一起维护，编制业务未接入应用代码。

| 独立样本 | 应观察的结果 |
| --- | --- |
| 岗位核 5，已占 3，需求预留 1 | 空编 2，可用 1。预留中的员工入职成功后已占 4、预留 0，仍可用 1。入职失败则保留原预留 |
| 同一人同单位主岗、兼岗，跨两个部门 | 单位去重为 1 人，2 份任职。主岗占编时，兼岗免占编合计占 1，另占编合计占 2。两名各承担部分工作的占编任职人员计 2 个名额 |
| 部门有岗位核 2、核 3、未核编 | 可见完整时显示已核定合计 5，未核编 1 岗。某岗满编时另一个岗位的空编不能直接使用 |
| 未来核 2，已占与预留各 1，拟减至 1 | 该段拒绝。释放预留后可减至 1。暂停补员时账面仍可有余额，新的预留或任职按暂停生效日拦截 |
| 直接核编和并发 | 有权人在正常菜单保存即登记，按业务日生效。未获权写入拒绝。同一最后名额在实际接入时须用两个数据库连接验证，不能用算例充当并发结果 |

原 059、075、078 三项只适用于旧计量方案，保留定位并退出产品验收。保留其他业务身份及受影响的用例，以整数、真实任职、日期和当前权限重述。新增 094 单独验证部门汇总、可见范围和归属变化。[现行验收表](../specs/m03/313-position-capacity-contract.md#m03-ac-094)
