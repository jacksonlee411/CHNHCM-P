| 事项 | 本次决定 |
| --- | --- |
| 交接 | 有权人从原单指定接替关系和有效期间。到期按日结束，延期在原安排上重验。逐岗预设同期上限和跨次累计天数退出当前范围。企业另有硬性制度时再考虑该项政策。 |
| 录用 | 预计范围用于寻访和草稿。正式录用确认一个到岗日，改期一并重验拟任期和预留。允许在多个日期中任选一天到岗的正式承诺留待有实际需求时处理。 |
| 实况与差额 | 人事按依据更正实际履职，编制按来源计算实际超编和承诺缺口。调编、调岗、结束任职等原业务记录说明从何日起恢复足额，省去派责、手填余量和结案。 |
| 运营观察 | 原 AC106 移出编制交付，原编号可查。[X06](../architecture/target/modules/x06.md) 在有明确使用者时按需验收。延误归因取已有业务记录，缺依据记为未知，经办人可照常办理招聘和任职。 |
| 部门与跨域 | 部门小计只列启用岗核定合计和未核编岗位数，停用岗保留额在岗位明细可查。人员关系及主选择由 [M04](../architecture/target/modules/m04.md)统一定义。锁序由[共同事务合同](../architecture/target/10-ddd-and-state-contracts.md#staffing-quota-transaction)维护，313 验收名额和任职能否一起生效及查回。 |
