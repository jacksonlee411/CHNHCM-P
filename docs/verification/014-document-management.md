## 4 复核发现与修正

首轮工具检查通过后，代码阅读及隔离临时目录反例复现发现以下问题。它们均已修正并加入回归用例，不能把首轮工具通过视为已排除这些问题。

| 问题 | 修正及拒绝行为 |
| --- | --- |
| 行内代码锚点示例被当成真实规则定义 | 提取实际锚点前排除围栏与行内代码；示例既不占号，也不能满足链接目标 |
| 已替代文档可以指向 planned/draft/cancelled 等未采纳提案 | 替代目标须已有正文，并处于 active/superseded/retired；保留合法历史替代链 |
| 已取消且无正文的条目可以声称已归档 | archive 必须指向实际普通正文；旧路径、编号、原类别和归档年份一致 |
| 导入/模板目录可隐藏实际编号文档 | 全库未登记的三位编号文件名或 CHNHCM 编号 H1 均拒绝，原始两位导入标识及围栏示例仍允许 |
| 模板说明笼统要求验证报告领取新编号 | 明确报告登记到 verification_records，复用关联文档 ID，以日期或后缀区分补验 |

审阅者为 `/root/document_governance_review`（Codex 独立代理）。其实际复现了替代和归档问题，复核修复后运行 `make docs` 和差异检查，结论为本轮文档治理范围 accepted。该身份及结论不代表人工批准，不扩展为产品、法规或完整历史的审查。
