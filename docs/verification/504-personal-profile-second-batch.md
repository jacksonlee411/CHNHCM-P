| 013 多地址与多名紧急联系人 | 两地址同时存在，第二条设为主要时撤下第一条。分别撤回任一行的主要标记写权后再次切换，整笔返回 403。两名家庭成员均可设为紧急联系人。清空唯一电话时返回对应行的紧急标记错误，补邮箱或同时撤下标记后可保存。员工本人的电话保持原值。 |
