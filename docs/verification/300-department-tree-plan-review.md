## 4 问题、修订及反例复核

| 问题 | 等级与原方案缺口 | 修订及文档关闭依据 |
| --- | --- | --- |
| R300-01 权限要求未形成可执行矩阵 | P1：原第2.4节把字段矩阵留到T00，未区分祖先最小引用与完整读取，可能漏掉“中间无完整read、下级可读”或通过箭头泄漏无权关系 | 第2.4节冻结五类读取矩阵；定位祖先区分node/context，只有引用权的祖先仅作路径上下文；范围先遍历真实边再按权投影。AC051覆盖A→B→C和逐字段／引用撤权；不增加树角色、不扩大普通列表门槛 |
| R300-02 保留草稿的承诺与现有接口／页面冲突 | P1：Go的draftPage失败使ResolveSelection整体返回错误；页面requestPage捕错clear，valid及导出依赖data。仅写“范围失效仍可导出”不能实现 | 第3.1节定义available／scope_unavailable的部门页状态；仅空编辑resolve可返回有效草稿加不可用页，编辑失败不提交成员和修订；第3.3节移除“无page就无有效草稿”的假设。AC050覆盖锚点被排除／仍入选、只读503、零文件及无page导出 |
| R300-03 单请求一致被误扩大为整树一致 | P2：原稿承诺单请求捕获和迟到取消，但未规定同日跨请求调动的父窗口失配、旧挂载及业务日乱序 | 第2.4／3.1节绑定代次／D／父身份，验证aroundId仍为直接子节点，观察新父后清理旧挂载及链并取消旧代次；最多一次自动重定位，之后显式重试。AC048／051／053分别验静态完整与并发刷新，不增加整树版本 |
| R300-04 重复游标拒绝与只读重试冲突 | P2：原AC047要求拒绝“重复页”，易实现成一次性游标；向前窗口字段和边界未定 | 第3.1节允许有效游标重复读取，事实不变结果一致；明确hasPrevious／previousCursor、严格排除边界、目标为首项的定位窗、绑定页大小与方向。AC047区分重试、客户端去重和非法游标 |
| R300-05 容量判据与既有合同不一致 | P2：原稿把普通列表统一写300ms，选择／导出仅笼统引用131/132/133，浏览器目标缺失 | 第6.2节以120第7节为既有判据入口：普通列表1／20会话300／1000ms，选择start和resolve均按会话数1000／5000ms；CSV单列语义和成本，5秒SQL／10秒HTTP不当通过线。树新目标和浏览器拟1500ms明确为本方案新增，开测矩阵列完整口径 |
| R300-06 无范围时切换参数及无效动作未闭合 | P2：接口拒绝无ID的includeDescendants，但原页面始终可切换；更换／清除动作的失效规则可能误清空未变化的选择 | 第2.3／2.6／3.1节约定无范围禁用控件且省略两字段，首次默认勾选；默认true与显式true同一查询身份；只在规范化查询实际变化时清空。AC049核对重复节点／全部动作零查询、原草稿保持 |
