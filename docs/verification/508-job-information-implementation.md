## 3 旧库、提交恢复与升级器

`00056` 为新回执登记返回任职，在同一提交中写入不可变的 `staffing.probation_receipt_assignment`。旧回执保留原行、摘要和修订。从原经办入口恢复时重核当前可见任职。实际修正旧办理走统一升级器 `-mode probation-reconcile`，用 `CHNHCM_DATABASE_URL` 指定运行角色连接、`CHNHCM_INSTANCE_ID` 指定客户，从标准输入读取经办人的普通登录。默认预检，明确加 `-apply` 才逐关系应用。报告给出扫描、差异、修正、待核和失败数，可见差异带办理身份。待核或失败返回非零退出状态。再次执行以锁内读到的当前来源为准。[迁移](../../db/migrations/00056_probation_receipt_assignment.sql) · [升级器](../../cmd/upgrader/main.go) · [逐关系核对](../../internal/contexts/staffing/infra/postgres/probation_repair.go)
