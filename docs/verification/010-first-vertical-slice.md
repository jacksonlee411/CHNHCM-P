### 3.2 真实数据库与 API

[集成测试](../../tests/integration/bu_test.go)从受控企业/账号初始化、实际 HTTP 登录开始，使用运行角色而非迁移管理员执行业务。主要独立预期和实际结果如下：

| 场景 | 操作与已核对结果 |
| --- | --- |
| 首条创建和日期查询 | 创建当日及未来 BU；未来首条保存成功，当日仍无适用事实；确切来源可读，首次真实提交前的 knownAt 为 NOT_RECORDED，资料及来源均清空 |
| 原子性与历史封口 | 身份、记录、修订、来源、结果、日志、Outbox 和授权判定共同落库；注入 Outbox 写失败时整笔回滚；运行角色不能修改、删除、清空历史或在旧来源追加成员 |
| 幂等、竞争和未知结果 | 相同规范编码并发只接受一笔；原提交并发重试保持同一结果，不新增来源/日志/Outbox；查回不存在的提交形成 not_applied，迟到原 POST 被拒绝 |
| 当前权限与证据保留 | 查询、历史、重试和结果恢复均使用当前权限；撤权后不得复用旧许可。字段遮蔽后不能通过搜索/排序推知隐藏字段，原授权输入/完整 Grant 依据不被后续变更覆盖 |
| 会话与输入边界 | 实际 cookie/CSRF/Origin、登录轮换、退出、账号停用、初始化冲突；拒绝重复 JSON 键、未知字段、非法根节点及越界输入 |
| 撤权排序 | 使用真实 PostgreSQL 锁屏障验证“请求先获得守卫”与“撤权先获得守卫”两种顺序；不以固定等待时间假定并发顺序 |
| 提交与崩溃 | 暂停未提交业务时不能生成提交证明；在“业务已提交/证明未落库”和“证明已提交/槽未推进”两处实际终止后端，恢复后原证明不变且不重办业务 |

| 安静期与设施故障 | 心跳只推进技术证据，不伪造 BU 事实/事件；槽缺失使写入和 readiness 关闭，拒绝自动重建槽 |

### 3.4 容量样本

独立新建数据库，2000 个 BU、每个一个来源/一条记录、20 个实际会话；先写完再批量采集。写入加采集耗时 8.616861652 秒，数据库约 21,714,623 字节。读场景各 100 次请求，20 并发；未主动清缓存。

| HTTP 操作 | p50 | p95 | p99 |
| --- | --- | --- | --- |
| 创建 | 50 ms | 60 ms | 84 ms |
| 列表（100 条/页） | 78 ms | 128 ms | 133 ms |
| 详情 | 22 ms | 38 ms | 38 ms |
| knownAt | 31 ms | 52 ms | 52 ms |

样本内无错误，页码超界会返回第 20 页且 count 为 2000。该样本不能证明持续采集延迟小于 2 秒，也不覆盖 2000×50 来源×20 期间、单 BU 1000 次提交、冷缓存/锁等待分布或完整 EXPLAIN 目标；这些随未来记录操作实施。

## 4 失败、修复与复验

早期真实验证和独立复核发现的问题已按实际影响修复：未知提交期间换标识会重复创建、当前字段授权与结果回读不一致、历史页面残留当前日志、未保存退出绕过保护、加载失败无重试、403 后查回终态不能解除等待、退出失败误将表单锁为已保存、错误焦点在控件重新启用前执行。复验覆盖上节正常及异常路径；不将测试中的宽泛编码定位器误点旧列表搜索框算作产品缺陷，已使用精确定位和页面就绪断言。

提交证据方面，初始实现错误地要求跨 BU 的时间按全局 WAL 顺序递增。核对 [PostgreSQL 18.6 xact.c](https://github.com/postgres/postgres/blob/REL_18_6/src/backend/access/transam/xact.c) 后，改为每 BU 前驱链顺序约束，同时保留“当前采样不得早于已解码/已证明提交”的真实回拨检测。容量与崩溃验证通过。

受控恢复原先过早清除错误标记，以及用 end_lsn 不变误判排空的问题，分别改为持久恢复阻断和按无 Commit 结束；实际恢复进程崩溃及 400 BU 多批次恢复测试通过。安全变更审计将被操作账号写入 target_subject_id，不再冒充 actor。

**尚未消除的是主机时钟回拨。** 单独 15 秒 realtime/monotonic 采样观测：单调时间增加 20.757415 ms，系统时间减少 2169.511652 ms，差值约 -2190.269067 ms。最终连续浏览器期间又观测差值 -1851.252741 ms，数据库记录 CAPTURE_CLOCK_REGRESSED，新写入返回 503。独立恢复后可完成受影响场景，不能据此宣称持续运行已通过；没有修改操作系统校时、删除逻辑槽、重写时间或放松保护。
