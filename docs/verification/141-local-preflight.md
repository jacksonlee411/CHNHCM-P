## 1 受测对象

2026-11-23 在 wt-dev-b、基线 `c8b63983edf859b1eb0259a644369b3184cfb9ec` 的未提交候选上执行。机器使用 Linux、Python 3.12、Go 1.26、Node 24.19、pnpm 10.24、PostgreSQL 18.6 与项目锁定的 Playwright 1.55.1。各轮文件树、逐项用例及阶段结果见[验收数据](https://github.com/jacksonlee411/CHNHCM/blob/061d28105966bd10eb1e3b0032cf2976a6448de4/docs/verification/data/141-local-preflight/checks.json)。合成夹具使用独立 Git 仓库和合成页面，真实业务由本仓正常预检另验。

## 2 候选与实际范围

| 场景 | 预期与实测 |
| --- | --- |
| 无差异、文档、限定未命中 | 通过正常入口分别得到无候选且零步骤、仅文档阶段、生成核对及浏览器清单通过。限定夹具清单 1 项，当轮 DB/API 与浏览器均执行 0 项。 |
| 暂存与未暂存内容不同、另有新文件和删除 | 检查后原暂存差异保留。将相同内容提交到夹具后，提交文件树与预检记录一致。运行中改动内容得到失败及前后两个文件树。 |
| 同一候选失败后重跑 | 仅切换夹具的外部故障条件。真实 Chromium 首轮 1 项失败，复验 1 项通过，两个目录记录相同基线与文件树。复验后首轮[遮罩截图](https://github.com/jacksonlee411/CHNHCM/blob/061d28105966bd10eb1e3b0032cf2976a6448de4/docs/verification/data/141-local-preflight/failure-masked.png)的 SHA-256 保持相同。另在同一工作树并行分配两个不重名的目录。 |
| 中断 | 向正在等待文档子进程的本地入口发送 SIGTERM。得到退出码 130，当前步骤与总结果均为 interrupted，已分配的运行目录可读。 |
| 生成物变化 | 对新增、删除、修改、等长修改后恢复时间戳均检出；相同内容的重新生成通过。运行后原输入和已有未提交修改保持。符号链接输入及 Git 隐藏索引项有显式失败。 |
| 真实业务前置 | `make ci-ready` 在完整差异上通过生成物核对、两个真实旧库测试、6 项浏览器回归及 5 项企业前置。共 11 个实际浏览器结果，未跳过。 |

本次先发现两项验证夹具问题。最初把两个仅有的示例入口同时纳入限定，真实清单核对发现空分片，业务未启动；保留失败后改用单入口复验。文档失败样例首次因同名目录使 Make 跳过命令，补上 phony 目标后，实际退出码与首失败保留断言通过。

## 3 同输入生成物计时

在同一机器、同一工作树、同一份生成输入上顺序执行旧、新、新、旧四次。旧实现取自基线的 `scripts/ci_ready.py`，共用候选自己的 Makefile、生成器和依赖。每次前后核对文件树，运行真实生成器并销毁副本。原始样本和边界见[计时明细](https://github.com/jacksonlee411/CHNHCM/blob/061d28105966bd10eb1e3b0032cf2976a6448de4/docs/verification/data/141-local-preflight/comparison.json)。

| 执行顺序 | 总耗时（秒） | 生成器（秒） | 其余环节（秒） |
| --- | ---: | ---: | ---: |
| 1 旧 | 14.720 | 4.729 | 9.991 |
| 2 新 | 10.779 | 4.135 | 6.644 |
| 3 新 | 10.827 | 4.160 | 6.667 |
| 4 旧 | 14.304 | 4.502 | 9.802 |

输入共 15,912 个文件、710,758,764 字节。总耗时均值从 14.51 秒降至 10.80 秒，本机这两组样本缩短 25.6%。生成器之外的均值从 9.90 秒降至 6.66 秒。

新实现将计算原件摘要合并到复制读取中，生成后仍逐文件比对字节摘要、执行位和文件集合。现有验证资料均参加隔离检查。这四次反映本机已有依赖与缓存的条件，远端托管成本、冷缓存和多机并发收益另行测量。

## 4 收尾与验收边界

最终实现另经直接入口 `make ci-preflight` 实跑，2 项 DB/API 和 11 项浏览器结果均通过。用真实 Go 小样本验证跳过、未命中时，即使 Go 进程返回成功，前置步骤也以失败结束。

`make check`（含 154 项 Python 工具测试、领域边界、Go 单元与 vet、前端类型检查）、`make build`、登记引用检查及差异空白检查通过。每次正常预检在独立目录内保存摘要、实际测试和已遮罩的故障附件。真实浏览器临时运行的容器、网络、卷及仓外设置由 smoke 回收。正式 PR 的三项门禁、整套 DB/API 与浏览器回归、业务容量及固定环境发布在本轮本地验收范围之外。
