## 2 验证与交接

目标模块从编辑源重新生成，七张受影响架构图在隔离文档工具目录渲染。初次图面检查发现中文显示为方框，G06 的招聘节点又与工资结果使用同一节点编号。换用 Noto Sans SC 中文字体并修正节点后，以 Mermaid CLI 12.0.0 和 Chrome 140.0.7339.186 重渲七图，逐张查看中文、节点及改动箭头。M03 和 M05 图的预留来源、C01 与 G06 的归属，以及 F01、F02、F07 的办理方向均与合同一致。每图的源文件和 SVG 摘要单独保存。[渲染清单](data/004-architecture-diagrams.json)

- 招聘和任职的实库用例从已有人员发出录用，覆盖接受、释放、按已接受版本转换、免占编、身份不足及重复入职。另复验 313 岗位核编、315 部门调剂及其迁移前置。两类用量按各自来源查回。[招聘预留](../../internal/bootstrap/recruiting_offer_integration_test.go) · [已接受录用转入职](../../internal/bootstrap/offer_hire_integration_test.go)
- 人员整页、住址与家庭、过期主地址、目录采用四个 DB/API 测试根通过。另在保存地址时用独立连接停住 M01 的发布写入，再尝试更改所选国家、省和区县，三行均返回 PostgreSQL 锁冲突 `55P03`。释放发布写入后，整笔正常提交，精确来源、父级换版、撤权拒绝和旧采用均通过。同轮复验业务单元固定启停的插入、删除、历史与恢复。[目录锁与来源实测](../../tests/integration/personnel_address_family_test.go) · [业务单元固定操作](../../tests/integration/lifecycle_pair_test.go)
- 临时 Chromium 从人员菜单办理四个受影响用例，含国家原文及目录采用、地址选项换版后重选、地址控件缩放及按服务业务日区分同名区县。四项与五项企业前置全部通过。临时库、容器、网络与私有配置已回收。[浏览器用例](../../tests/e2e/personnel.spec.ts)
