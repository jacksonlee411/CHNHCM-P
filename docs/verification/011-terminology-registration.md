## 2 采用术语与登记方式

人工维护 [terminology-glossary.json](../architecture/target/data/terminology-glossary.json)，通过既有生成器更新 17；未手工修改生成物或变更生成器。原 440 项的 ID、英文身份与首选中文保留，补充五个词条后为 445 项；对象绑定仍为 154 组，参考概念映射仍为 131 项。

| 术语或场景 | 采用中文及处理 | 登记位置 |
| --- | --- | --- |
| Business Unit | 保留“业务单元”；源名“业务单位”继续作别名 | 既有 M02 词条 |
| Adopted Reference / adoptedRef | 已采用版本引用；引用定位确切来源版本或不可变快照，采用事实由消费者维护 | 既有 X01 词条澄清，保留“采用引用”别名 |
| Known-at Time / knownAt | 已知信息截点；保留“已知截点”简称 | 既有 X01 词条澄清 |
| Business Effective Time / businessAt | 保留业务生效时间；本批查询用“查看日期”，写入用“本次生效日期” | 既有词条内登记 M02 场景说明 |
| Dated Slice 与 BU 查询状态 | 保留有效期切片；页面“生效记录”可含未来记录；未来首条统一显示“未生效” | 既有词条内登记场景说明，不新增持久状态或聚合 |
| Record Identifier | 记录标识；原“记录身份”作别名 | 新增 X01 词条 |
| Submission Identifier | 提交标识；原“提交身份”作别名 | 新增 X01 词条，不冻结接口字段 |
| Source Version / sourceVersion | 来源版本；“源版本”作别名 | 新增 X01 词条，与修订版本、采用引用区分 |
| Current Knowledge | 当前已记录信息；“当前知识”作别名 | 新增 X01 词条，可解释已登记的过去和未来事实 |
| Business Today | 今日业务日期；“业务今日”作别名 | 新增 X01 词条，保留 M02 时区及跨午夜规则 |

英文说明名属于项目用语；本轮没有核验或宣称它们是 Oracle 官方译名。保留变更、更正、撤销、停用、取消编辑的动作区别，以及认证身份、法律身份等各自含义；未对全架构、历史报告和来源包进行机械替换。用人单位等角色继续遵循 009。

## 4 原问题与修订关系

| 原发现 | 本轮修订 | 复核边界 |
| --- | --- | --- |
| P2：adoptedRef 定义为采用事实 | 010、011 与 17 明确引用及采用事实的区别，保留消费者未接入和不得回退最新的限制 | 只复核文档语义；不代表已实现消费者查询 |
