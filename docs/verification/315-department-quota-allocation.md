# CHNHCM-315 部门额度与同日调剂

## 1 办理入口与基线

本批从岗位独立签收提交 `dde88122` 开始。当时的菜单名为「编制管理」。当前管理员从「设置 → 职务配置 → 部门编制分配」选择部门，打开「部门编制」，点「调整编制」。表单按生效日带入部门和各直属启用岗位的原值，共用一个调整原因。只读 HR 用相同入口按日期核对调整前后数值，或在变更日志打开部门总额的当次资料。岗位明细继续提供各岗原件。[岗位独立签收](315-position-quota-implementation.md) · [315 第 4.2 节](../plans/315-staffing-quota-administration.md#42-部门控制及后续联验)

Go 在同一额度写入口按稳定顺序锁受影响部门和岗位，在事务中重读归属、权限、所读来源及后续节点。部门上限、岗位额度各有独立记录，只保存本次改变的目标。改隶或恢复岗位也检查转出、转入部门的全部受影响段。部门总额使用现有企业额度授权，岗位可限定至获权的稳定岗位；部门身份经 M02 的当前权限读取。受限者的读结果省略总额与待分配，写冲突信息按可披露范围返回。[业务合同](../specs/m03/313-position-capacity-contract.md#m03-br-040) · [Go 分配校验](../../internal/contexts/staffing/application/allocation.go)
