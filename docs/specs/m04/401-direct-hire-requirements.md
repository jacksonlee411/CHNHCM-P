# CHNHCM-401 直接入职业务规则与验收

本规格用于人事从已有人员档案办理直接入职。T02 准备条件，T03 分模式交付。下文普通劳动关系采用一个客户样本。其他客户按其已生效的用工规则取用所需资料。[实施方案](../../plans/400-hire-readiness.md) · [登记表](../../governance/registry.json) · [M04 领域边界](../../architecture/target/modules/m04.md)

首笔入职在「职务信息」形成所属关系和首任职的创建记录。本人的雇用记录编号、后续兼岗、转正、变动及更正由 506 持有。401 继续持有首次入职的资格、原单、两层主选择与未来首单撤销规则。[职务信息业务效果](506-job-information-records.md#m04-br-011)

## 1 谁可以办、凭什么办

<a id="m04-br-001"></a>
**M04-BR-001 办理权限。** 人事经办人从「人员 → 员工 → 本人详情」起办，须有当前客户的入职动作权、对本人的入职核对用途、对拟任单位及组织的相应办理范围、对实际输入的字段权。各项操作分别按完整授予核验。仅有部门权限不能据此发现尚无任职的人。本人、登记人、经办人、组织管理员各依其有效授权访问。只读者可看获权的关系摘要，原件另核历史权。核对证件明文、核准高影响动作、更正、撤销分别授权。[授权合同](../../architecture/target/modules/x03.md)

<a id="m04-br-002"></a>
**M04-BR-002 身份与任用依据。** 沿用原人、原编号。普通样本用档案姓名及一份可用于本次办理的居民身份证或护照核对本人。M01 已有适用证件的类型、号码即可采用。合格的补充证件也可用，无需改为主要证件。证件到期后仍可依据原档识别本人并保存入职。未记截止日仍保留未知。只有适用政策明确要求核实期限、查验原件或另作决定时，才检查相应资料，复用仍有效的原档事实或核验结论。原档资料仍不足以判断时才补缺项或处理矛盾。常规办理免交证件影印件、核验单和其他个人资料。M04 只固定本次采用的来源。[人员身份边界](../../architecture/target/modules/m01.md)

| 拟办理的关系 | 需要核实的身份、人事依据与角色 | 办理结果 |
| --- | --- | --- |
| 直接建立劳动关系 | 凭实际任用决定或入职通知。系统内已有决定时直接引用并带出安排。无编号通知等人工依据写一条能找回该决定的说明即可，例如“人事部 3 月 26 日发给甲的入职通知”。原单列多人时只需能辨认本次人员。经办人核对本人、单位、到岗日及首任职，可补齐原单未载的办理字段。 | 一次保存工作关系和首任职。无需为手工依据编单号、造行号或上传附件。关系开始日取约定或经核实的实际到岗日。书面合同的订立日另由合同办理记录。 |
| 派遣且实际到岗 | 按派遣／接收安排核对本人、双方角色、日期与拟任工作。已有安排直接引用。A 用人、B 接收时分别查两方的资格。 | 新建关系时同时登记首任职。接收单位变化落在对应任职期间，既有关系下增任职由 T04 办理。 |
| 明确的非工作关联，或来自已接受录用 | 前者按关联性质及主体用途核实。后者依 M05 候选绑定、录用、到岗日和交接的确切版本。 | 非工作关联按其专项登记，可无任职。招聘交接随 T06 从原录用办理，已承诺的份额沿原单处理。 |

<a id="m04-br-003"></a>
**M04-BR-003 动作与必要决定。** 有权人凭人事依据直接保存。系统采用有效的入职类型、原因、初始状态和政策版本，唯一适用原因直接带入。客户明确要求单独核准或职责分离时，才核对绑定本人、组织、日期及内容的有效决定。原任用决定已满足的条件直接沿用，已撤销或实质内容失配的须重新核定。目录停用后仍可解释旧单。[领域决定与生效](../../architecture/target/10-ddd-and-state-contracts.md#21-领域核验审批与生效)

首个合成客户的规则版本为 `T02-employee-1`。普通员工关系 `Employee` 采用动作 `Hire`、原因 `direct_appointment`、初始状态 `Active`。在人事管理用途 `personnel_management` 下，先确定此人的主工作关系，再确定该关系内的主任职。候选范围须完整且获权，已有适用选择可沿用，唯一目标自动带入，多项真实选择才需经办人指定。[Go 准备样本](../../../internal/contexts/staffing/application/hireprep/prepare.go)

## 2 拟任期间的组织、岗位与主选择

<a id="m04-br-004"></a>
**M04-BR-004 主体用途覆盖。** 系统用 M02 已登记的主体启用、资格用途和必要的 BU／地点绑定核对整个拟任期间。多家合格时按真实用人安排选定。缺一天、用途互相矛盾或只有受托签约资格均无法办理。任期未定时核对已知未来变化和最后一段开放记录。资格依据由组织管理员在声明用途或资格、期间、限定条件变化时维护，经办人无需逐人交单位证照或证明未来无变化。[M02 用途与绑定](../../architecture/target/modules/m02.md) · [主体与关系性质](../../adr/009-mainland-organization-terms.md)

<a id="m04-br-005"></a>
**M04-BR-005 任职模式。** M03 按企业、人员类别、用途及期间解析唯一政策。仅按职务核有效部门与职务，全段零岗位、零占编。按岗位还核岗位的有效期间、归属及补员状态。免占编保留真实岗位任职和该段的 M04 使用来源。只有占编段才核余额，每份占一编，由系统取 M04/M05 的实际使用或已确认的零起点。占编段缺额、用量未知，或任一段的必要规则缺失、冲突，整笔拒绝。部门待分配数不计作岗位余额。已实际履职的补录另核事实，满编或暂停时按 313 记实并显示差额。[岗位口径](../m03/313-position-capacity-contract.md#m03-br-025) · [补员状态](../m03/313-position-capacity-contract.md#m03-br-029) · [履职事实](../m03/313-position-capacity-contract.md#m03-br-036)

<a id="m04-br-006"></a>
**M04-BR-006 两层主选择。** 每个用途先在本人关系中选主关系，再在各关系内选其主任职。人事管理用途在有效 Employee 期间须恰有一段合格主关系，每段适用 Employee 关系各有一份合格主任职。Active 及政策明确合格的 Suspended 任职可选。仅登记、未来入职前或全部退出时，当日允许为零。实际工作的非 Employee 默认允许零或一段主关系，被选关系须有合格主任职。非工作关联默认可无主任职。其他用途按明示政策。首次两层各只有一个实际合格目标时，系统随保存确定。候选是否唯一按真实关系判断。已有有效选择沿用，多候选且确需变更时才由获权人取舍。这些选择确定适用关系和任职的管理归属。员工列表的人层主岗固定为 0 号，另一关系内即使只有一份任职，也按本人原正号显示兼岗。主兼岗转换后置。终结、撤销、更正、政策激活逐段重验资格、唯一和必需覆盖。[主选择政策及 AC02](../../architecture/target/10-ddd-and-state-contracts.md#ac02)

已有工作关系时先按实际任用安排区分另一段真实关系与原关系内增加任职。另建真实关系须有可区分的任用依据并核两层选择，增加任职从原关系办理。再聘沿用本人和人员编号，在本人原 0 号雇用记录下接入新关系、新任职，原已结束的任期仍可查。[雇用记录编号与再聘](506-job-information-records.md#m04-br-009)不能因为取得新提交号或更换单号，就把同一工作安排登记两次。

## 3 更正、撤销与同日事实

<a id="m04-br-007"></a>
**M04-BR-007 三种不同的办理结果。** 放弃未保存草稿为零业务写入。已保存的未来首次入职可由获权者在生效日前从原办理撤销，逐段撤去该次关系、首任职、必要选择与适用占编。存在其他关系时按适用的主选择政策衔接。若导致必需的 0 号主岗覆盖中断，或存在未合法处置的后继，整笔拒绝。已生效的资料录错时，定位原办理及相应修订更正。确已发生的离职、调回等真实行为另记新动作。更正与撤销追加修订，原依据、原采用和原回执均可按当前权限追溯。[主兼岗规则](506-job-information-records.md#m04-br-009) · [未来首次入职及撤销](../../architecture/target/modules/m04.md)

<a id="m04-br-008"></a>
**M04-BR-008 同日多项人事动作。** 每个真实动作有稳定身份。系统记录业务日、类型／原因、实际修改、经办人和记录时刻。普通资料更改保留前后值，更正沿用原笔及已有来源。需任用或变动依据时引用已有安排，手工通知可简述来源。已知发生时刻时据实保存，依据只载日期时由系统记明。独立动作直接登记，一项办理可同时改两个字段。有真实先后时关联确切前项修订，必要依赖另记。矛盾修改须明确承接或更正。撤改时重算受影响期间并保留独立后项。每个来源内同一任职每天只有一份适用状态，按有效业务身份计动作，更正次数另计。[同日状态与反例 AC03](../../architecture/target/10-ddd-and-state-contracts.md#ac03) · [106 六项的处置](../../adr/106-same-day-personnel-actions-and-daily-state.md#t02-decision-scope)
