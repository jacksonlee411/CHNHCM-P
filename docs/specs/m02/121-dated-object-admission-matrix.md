## 4 样本、基线与执行合同

### 4.1 非敏感独立预期

[contract-fixtures.json](https://github.com/jacksonlee411/CHNHCM/blob/061d28105966bd10eb1e3b0032cf2976a6448de4/docs/verification/data/116-r0/contract-fixtures.json)使用合成企业、BU和部门别名，逐条保存before、command和expected，预期由合同手工给定。日期固定，边界是[开始,结束)；null结束表示开放期间。别名由未来驱动映射到隔离库真实身份，禁止调用被测候选/路径算法反算expected。每案例actual_result均为not_run。
