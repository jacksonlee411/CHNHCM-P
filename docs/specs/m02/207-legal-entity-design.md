# CHNHCM-207 法律实体基础维护合同

登记信息：[registry.json](../../governance/registry.json)。适用范围：LegalEntity基础资料的首阶段真实接入；推进及验收由[206](../../plans/206-legal-entity-implementation.md)持有。依据[009](../../adr/009-mainland-organization-terms.md)、[M02目标](../../architecture/target/modules/m02.md)、[120](120-dated-maintenance-technical-contract.md)、[121](121-dated-object-admission-matrix.md)和[124](../../guides/124-dated-object-admission-and-capacity.md)。本合同不新增各地区法律资格政策。

## 1 对象、角色与正常任务

LegalEntity是企业内独立组织主体，稳定UUID及企业内唯一编码，不复用BU/部门/地点身份。组织管理员从“设置 → 组织配置 → 法律实体”创建、查询、维护及追溯；查询者可读取及导出获权资料。首条默认1900-01-01，仅为配置初始默认，不表示成立、登记或法律关系起点。企业有效下界及用户明确日期按202处理。

基础资料不推导用人单位、用工单位、付款、扣缴、参缴或成本角色；分支与非法人组织可单独登记。用途及具体人员关系由009分责，后续用途声明、真实组织绑定和M04采用另立专项。编码不能被更正为另一主体，不按名称或登记号码合并对象。

## 2 强类型资料及接入差异

| 字段 | 合同 |
| --- | --- |

| name/nameEn | 名称必填、英文可空，沿用现行NFC/长度/文字规则 |
| countryRegionId | 必填，全球CountryRegion稳定UUID；不要求GeoArea，不复制国家名 |
| subjectType | 必填枚举legal_person（法人组织）、branch（分支机构）、unincorporated（非法人组织）、other（其他组织）；声明类别不等于资格结论 |
| registrationType/registrationNumber | 可同时为空；非空分别最多80/100字符，成对保存；类型由用户填适用登记名称，号码按文字保存，不剥除前导零或改大小写，不在本阶段作全球唯一/法律有效性校验 |
| establishingOrganization | 可空、最多200字符的设立单位说明；保存文字依据，不替代后续稳定身份绑定或委托事实 |

可空字段缺省保持，显式null/空白清空；必填字段null拒绝。登记及说明先拒绝控制字符再修剪首尾空格。成对约束评价同一补丁完整应用后的最终记录，不在逐字段赋值中检查临时半对；只提交一个变化字段不等同于两字段都修改。改国家或类别不自动删除登记/设立单位资料，也不自动宣告登记继续有效。隐藏字段不在表单/CSV中泄露。所有最终实际变化，包括删除、分类变化和停用继承导致的隐式变化，均核对应字段写权。

## 3 国家引用与完整维护矩阵

基础资料保存国家的稳定身份、采用日及确切sourceVersion/recordId/revision，不保存当前名称替代引用。候选由Go计算拟动作采用日期；前端只传拟动作、日期、分类及国家变更，异步请求归属与会话变化时丢弃旧响应。

| 最终动作 | 是否新采用 |
| --- | --- |
| CREATE | 首条日采用启用国家 |
| 新CHANGE或插入 | 国家与最终前序不同才采用；相同时继承前序准确证据 |
| 普通更正名称/类别/登记/说明 | 国家不变则原采用保持 |
| 现有非停用记录改日、改变操作分类或换国家 | 按最终记录日重新采用；只更原因不重新采用 |
| DEACTIVATE、分类最终为停用 | 完全继承最终前序资料及证据，无独立国家采用 |
| 新REACTIVATE、固定期间恢复端 | 恢复日重新采用；目录停用/失权则原子拒绝 |
| 固定期间只改停用端、恢复端原日期/国家不变 | 恢复端原采用保持 |
| 删除/分类/固定两条删除 | 最终独立后继资料保持，停用重继承前序；延长旧启用期不算新采用，不补全期间国家覆盖 |

所有需新采用的国家UUID去重排序，在同一写事务及单调守卫预算内加国家共同锁，再重读当前源，核采用日启用及当前country.read；采用日不是当前记录时另需country.history.read。必要字段name/state/effectiveDate均须获权。先停用后采用拒绝；先采用后目录停用允许双方成功，原法律实体证据保持。纯名称等不变引用维护不取得国家写锁。候选读取失败只影响候选，不清空已选身份/其他输入；换动作、日期、分类、主体或会话后晚到响应不得覆盖。预览和候选不是保存许可。

只有法律实体read权不足以读取国家标签。确切采用标签按当前国家read/history.read交集裁剪，即使采用源恰为当前头也不冒充普通今日读取；失权只给受限提示，不用当前名补旧名，不改历史。不变引用可内部继承，无需用户重新选用；新采用不可借继承绕权。

不变引用的编辑上下文另返回按原采用和当前授权投影的countryName/countryRestricted；可选国家列表不能替代该权限判定。原采用不在当前可选集合时，只要确切标签仍获权就保持原名；历史权限撤销则清理先前加载的旧名，不能凭当前候选包含同一国家而保留。

## 4 存储、API、授权与可靠提交

独立legal_entity身份、history、dictionary、shape、read、terminal及selection表组，沿用模型5/read-segment-4/query-seal /3的既有紧凑存储机制。集成后追加迁移00015（原分支00014在与企业维护合并时重编号）；无破坏性down。对象锁、提交锁、封套类型和事件为LegalEntity独立命名空间，来源/修订/记录UUID完整，准确历史不可变。与其他对象共用企业身份但不共享业务来源表。法律实体写入与企业首条日期修改共同锁定企业行，并在锁内重新读取日期下界；企业后移首条日期不得越过已有法律实体首条日期。企业停用期间不追加法律实体有效期间限制。

HTTP前缀`/api/v1/legal-entities`，类型为LegalEntityContext/Record/Detail/Result等；入口包含context、operation-reasons、reference-context、列表、详情、changes、navigation、selection/start/resolve/cancel、export、创建、records及correct/delete/redate、deactivate/reactivate、lifecycle-pairs/insert/maintain/delete、preview和submissions/{id}/resolve。输入只接收本类型合同；用途/BU/地点/人员字段拒绝。

X03动作前缀legalentity，read/history.read/export/create/record.add/record.correct/record.delete/record.redate/deactivate/reactivate/lifecycle.pair。scope_kind为enterprise；读取和各动作写字段分别裁决，客户端不得指定另一企业扩大授权。查询者获得read/history.read/export；管理员获得完整动作。身份/动作先于目标诊断，显式要求与最终差异均核验。

终态仅在确认事务提交后发布；同主体/类型/提交号相同摘要重放，变摘要冲突，其他类型相同提交号隔离。未知结果仅按原身份查回，不盲目重放或把超时当未保存；会话/权限变化清理受限正文，保留恢复引用。字段错误定位并保留仍有权草稿。

## 5 查询、导航、选择及CSV

列表按服务端今日，未来首条显示未生效；关键词为获权编码/名称，状态、单列条件及countryRegionId交集。支持编码、名称、英文名称、主体类别、登记类型、登记号码、设立单位说明、状态和日期列条件/排序；国家使用稳定ID条件。默认无编码读权时以UUID排序，显式无权字段查询/排序拒绝。分页20/50/100。

详情导航与列表共享完整条件、排序及授权；返回位置和匹配总数，前后只一次导航，锚点不匹配返回相应状态不越界；返回列表保留筛选/页码及高亮，导航辅助失败不卸载当前详情。

选择草稿捕获当时全部匹配的获权UUID，翻页/排序保持，条件集合变化重选；增量编辑校验修订，未知start不自动重捕获。新匹配对象不自动加入，已捕获且仍获权成员不因不再匹配而丢失；跨日/会话/过期按既有草稿合同失效。

CSV固定十列：编码、名称、英文名称、国家/地区、主体类别、登记类型、登记号码、设立单位说明、状态、生效日期。各字段需当前读权及export；国家标签另需准确采用历史权。实际入选成员失权整笔拒绝；已排除成员失权不阻止其余导出。先完成验证与文件封存再返回，保留既有公式注入防护。

## 6 页面、测试与后续交接

使用既有主题、列表详情、时间线、日志与共享日期组件；创建/更正直接呈现获权字段，主体类别下拉，国家候选标注Go返回的可用结果。更正默认原值，实际变化自动计算；停止记录资料只读继承。前端不实施时间线/资格/登记成对业务判定，错误由Go定位。

独立预期覆盖分支/非法人、全球国家、登记半对与清空、国家竞态/旧证据、字段权限、完整维护、固定选择、丢响应及重启；具体矩阵、规模和完成门槛见206第6节。资产采用仅随真实本对象结果登记，已有地点通过不能直接当法律实体通过。L2必须另外定义用途区间、资格依据和绑定/引用保护，L3用真实M04关系检验，不预造采用回执。
