## 1 任务、归属与接入原则

### 1.1 用户任务

管理员查阅和维护国家/地区及本期区划，在相应地区建立实际办公、工作或组织地点，修改地址、办理启停并查阅旧来源。查询者从相同正常菜单读取获权资料。来源维护者沿受控装载入口引入固定地理包；不向普通用户开放自由创建官方行政实体。

本方案区分三类事实：国家/地区目录、行政及地址区域目录、企业地点。地点是M02 Location，有企业内稳定身份和编码；CubeBox的地址地名、Odoo的res.city、员工个人地址均不是这个对象。企业地点不得按同名区域自动生成。

### 1.2 所属域与能力

本批拟将CountryRegion和GeoArea登记为Organization拥有的地理参考对象，Location继续属于M02组织对象。国家/地区和区划在客户实例内共享，不按BU复制；地点归企业，首版不要求管理BU。编码/区域范围不表示主权分类，四地选择器使用CN、HK、MO、TW来源代码定位地址范围。

X03裁决当前权限；X02继续拥有适用/默认政策，不持有这三类对象的第二份事实。本批不新设第18个上下文，不把Organization完整内核搬到X01。未来其他域只通过公开只读引用合同使用地理对象。

本方案持有三类对象的本批设计范围；T00按对象同步007、目标M02及上下文范围说明，目标生成源及产物按本仓修订链更新。文档评审通过不等于架构登记、数据冻结或产品实现已经完成。

### 2.1 M02-BR-200 全球目录与四地办理范围

国家/地区候选基线为CubeBox固定包的251条，与本机Odoo当前国家代码集合一致。251是Odoo国家/地区目录条数，不是主权国家数，也不等于251条正式ISO分配码；XI、XK等保留其来源命名空间和原文，不冒充另一标准的分配事实。

### 2.3 M02-BR-202 来源、身份与装载

各对象用完整内部UUID。国家251条资料随应用版本保存于[countries.json](../../../internal/contexts/organization/infra/countryseed/countries.json)，版次、原始出处与许可随[离线说明](../../../internal/contexts/organization/infra/countryseed/NOTICE.txt)及既有来源包保存；不向HTTP资源、页面或字段权限投影提供方来源资料。内部初始化映射继续保证已有身份和重复装载稳定。区划来源键与业务代码分开保存：Odoo XML ID、民政部代码、NLSC代码、香港代码和澳门来源键均携带来源命名空间；不得用名称、数组下标、邮编或来源数据库自增ID作本仓身份。

来源包至少记录提供方、来源路径/URL、许可、源提交或版次、文件摘要、观察日期、条目数量、转换规则和拒绝清单。标准码是字符串；同一方案/地区/有效期间内唯一。名称可同名，精确重复来源键拒绝或幂等返回同一对象。

首版以国家251条、正式区划筛选结果及核验后的澳门分区生成独立CHNHCM种子包。保留所有输入原字节；未知代码、未匹配地名和414条旧待核对地址只作来源资料，不进入官方区划候选或自动生成Location。已知来源失效不等于物理删除已有身份。

装载使用一个固定离线Go命令，调用现有应用服务及submission；逐对象独立事务、父先子后，失败保留原提交身份并查回/续做，不假称整包回滚。来源键到实例UUID及提交身份的映射稳定，已完成同摘要包重复装载零新增事实；这份映射和既有终态足以恢复，已受理行复跑不新增来源，未受理行仍可续做；不另建任务状态机、队列或同步平台。

国家目录及CN/HK/MO/TW区域分别核对并登记完成版次，只有完成的区域目录开放地点候选；局部失败不使已完成的国家或其他地区失效。装载报告可以查看已完成/失败项，未完成区域不被当作完整目录推断“最具体层级”。澳门无已核验区域时按第3.4节仍可维护国家/地区加详细地址。后续包差异由明确维护命令处理，不自动覆盖已修改资料。

构建、初始化验收及运行不连接CubeBox/Odoo；源同步脚本含写操作，只作原件保存，本仓不得直接调用。

<a id="m02-br-203"></a>
### 2.4 M02-BR-203 默认日期与三类时间

三类对象首次新建默认1900-01-01，遵循202。这是目录或主数据在系统中的初始化生效起点；来源数据截止日、发布/观察日期、已核实实际行政沿革日期分别保存。未知实际沿革日期保持空，不因默认1900而补造。

用户或导入源明确给出的生效日期保持。普通列表仍按服务端今日，详情跟随所选记录；后续变更/插入/启停沿共用位置和生命周期规则，更正保留原值。不把目录包观察日自动设为地点业务日，也不把1900目录外推成完整历史行政事实。

## 3 强类型对象与关系

<a id="m02-br-204"></a>
### 3.1 M02-BR-204 对象资料与字段边界

| 对象 | 自有资料 | 身份/关系与权威位置 |
| --- | --- | --- |
| CountryRegion | 编码、显示名称、英文名、可选电话区号 | countryRegionId稳定；客户实例目录内唯一来源代码；不归属BU |
| GeoArea | 名称、可选英文名、区域性质、层级类别、官方代码及方案、国家/地区ID、可选上级区域ID | geoAreaId稳定；父关系唯一保存在该对象按日资料；不写部门Hierarchy |
| Location | 企业内编码、名称、可选英文名、国家/地区ID、可选最具体区域ID、详细地址和可选邮编 | locationId稳定；企业内编码唯一；引用对象及当次确切来源证据由Location来源保存 |

GeoArea区域性质区分administrative与address_region；二者不能仅因共用页面被混称正式行政区。无官方码的地址分区用内部身份定位，官方码留空。国家和官方区域的新增/代码变更由受控来源维护办理；普通页面可维护获权显示资料和目录启停，不自由发明官方代码或自由换父。

Data、Patch及公开DTO均为各对象强类型。补丁保留缺省/显式null/空文本区别；Normalize只处理新输入，Clone隔离可变字段，EqualData比较业务值，EqualRevision比较准确引用结构。缺英文翻译保持空，不将中文重复写入英文栏冒充译文。提供方原名及版次保存在离线版本资料；国家及区划资源不重复返回这些字段。已有不可变初始化证据和业务快照保持，不静默清洗旧快照。

行政父关系无需另建通用树平台：GeoArea当前树由各对象头按日组合，父边不在GeoArea和另一通用关系表双写。搜索路径是派生结果，不能作为另一套可编辑地址事实。

<a id="m02-br-205"></a>
### 3.2 M02-BR-205 目录启停与引用资格

国家/地区及GeoArea的启用/停用表示本系统目录能否新选，不表示国家或行政实体成立/撤销。普通用户不直接编辑active布尔值；采用共用按日操作表达目录状态，真实行政沿革必须另有来源依据。

GeoArea结构关系在所有受影响日期段校验：父身份存在、同一国家/地区、类型/层级组合合法、无自指及当前/未来循环。一个日期段最多一个父；直接根节点的parent为空。父目录停选不删除身份或批量停用子对象；新候选要求按办理日期解析的节点及其祖先目录均可选。

地点创建、国家/区域引用实际改变、启用资料记录改日或形成新的重新启用记录时，由Go按该次采用日核对四地范围、目录完成状态、节点/祖先资格及来源。完整维护按第3.7节矩阵决定重新采用、沿用或停用继承；停用记录改日仍继承最终前序资料，不独立采用。采用日由Go确定，仅供内部引用资格及历史投影使用；普通详情、表单不显示“地址采用日期”，用户只处理记录生效日期。普通新增资料记录若仅变更名称、门牌、邮编等而沿用原区域引用，则复制原采用日期和证据；新增记录日期本身不把不变引用变成重新采用。目录后来停选不自动停用地点，不清空已采用地址，无关修改不强迫重新选择地区。已失权的引用标签仍裁剪；原引用有效保留不授予读取权限。

目录引用是某次资料保存的采用依据，不复制部门“父BU必须覆盖子部门所有启用日”的持续运营约束。新选资格、结构父边合法性、已有地点采用保护分别检查。当前页可标明仍使用旧来源的引用，但不虚构已完成重选。

<a id="m02-br-206"></a>
### 3.3 M02-BR-206 当前路径与确切来源

GeoArea列表路径按今日解析；详情所选记录覆盖今日时沿用今日，否则使用所选记录生效日，Go返回明确的路径日期。首版显示该日的一条路径，不提供记录全期间的分段路径浏览，也不新增通用查看日期控件。祖先更名不改后代身份或来源，当前路径读取只解析所需祖先链。

准确来源保护的是该对象当时的资料与引用采用。国家/父区域/地点区域每次首次采用、实际换引用或改采用日时，在该来源内保存采用日及有限祖先链的稳定身份、准确来源/记录引用；显式sourceVersion显示这份采用时证据，不从最新祖先重建。未变的引用沿用原证据，源内已有相同结构可复用现有紧凑存储机制，不为每次名称更正复制全部祖先历史。

G3的GeoArea采用证据含采用日、国家引用以及从区域根到直接父的有序链；每项保存对象类型、稳定ID、准确sourceVersion、recordId和revision，采用日须落在该准确修订的有效期间。根区域的父链为空，仍有国家引用；目标区域自己的记录由其来源承载，不把自己再塞入父链。后续地点采用链才包含最终区域节点。读取标签按所存引用定位原修订并执行第7.2节当前权限，不把父节点昔日采用的祖父版本冒充本次统一采用日解析的版本，也不以最新名称回填。

Location保存详细地址及准确区域引用，普通详情按该记录的采用证据显示地址。目录后续更名不悄悄改写已保存地点；门牌/邮编变更产生地点新来源，但不自动刷新不变的区域引用。历史读取继续执行当前history.read及字段权。

本期不复制部门覆盖整个所选期间的path_evidence分段，不建立第二份GeoArea父边表、独立关系来源、反向地点刷新任务或全历史树版本。有限链只服务本次准确引用；结构合法性仍按第3.2节覆盖受影响期间。内部引用沿现有来源协议，不新增外域adoptedRef占位入口；原结果查回定位原对象、原来源及原记录。

<a id="m02-br-207"></a>
### 3.4 M02-BR-207 地点地址输入

地点的国家/地区和详细地址必填；中国大陆、香港、台湾要求选择本期已核验的最具体可用区域，允许第2.2节列明的真实缺级。澳门区域按已核验覆盖提供，不能为了使其必填而添加自造分区。前端可分层搜索/选择，API只提交国家/地区和最终区域ID，祖先路径由Go解析。

2026-11-15用户决定：地点地址表单、详情和变更日志统一使用固定标签“行政区划”，保留“国家/地区”；占位提示统一为“请选择行政区划”，不按所选国家/地区切换层级标签。此为界面命名，不改变GeoArea的区域性质、实际层级或准入范围；基础资料列表标题使用“行政区划”。地区控件在同一弹层连续选择：中间层保持展开，末级选择完成才关闭，结果回填输入框；重新展开定位已选上级并高亮当前项。弹层内展示可点击的上级路径及返回上一级。大陆省级选项一轮完整显示，较长搜索结果按现有游标滚动追加、保留已加载项，并提供键盘可达的加载入口。香港、台湾按实际层级，澳门保持基础地址，不强造省市区三层。

CN/HK/MO/TW是本期可选范围，列表仍可展示国家目录中的其他条目。切换地点国家/地区会使不匹配的草稿区域失效并要求重选；不能带着旧区域身份保存。选择区域不自动创建工作地点，地点名称也不从区域名称推断。

### 3.5 G3首批结构维护边界

G3采用G0固定结构，首次创建后不开放国家、代码方案、代码、性质、层级及父关系的修改。普通资料补丁只允许名称、英文名；目录启停沿共用命令办理，未知/未开放结构字段直接拒绝，不能忽略后伪报成功。初始包检查及创建须核同地区、合法层级、存在的父、无环、日期资格；已发布后名称/状态维护不获取结构排他守卫、不扫描后代。

具体维护边界沿G2：普通新增资料、停止/恢复选用只允许在末条记录之后追加，显式日期须满足共同位置和状态规则；停止选用不携带资料补丁，恢复可带获权的显示资料变化。更正定位原recordId及revision，只改名称/英文名，保留生效日、操作类型、原因和结构；首条也适用，不把通用首条改日能力自动接入。允许更正的记录种类及停用继承沿共用内核，不直接改active。不得通过预览、未知字段或旧草稿绕过；no_change不新增业务来源，但原提交终态仍按共同协议保存。纯显示资料变更和目录启停均沿用原国家/父采用证据，不重验其新选资格；停用父不阻断子目录名称更正。

第3.2节及第7.1节的受影响期间、关系守卫和双向改父并发合同保留给后续有来源依据的结构修订命令，G3不建设该入口。父关系仍属于按日资料，不能因暂时不开放编辑而另建第二权威关系表。结构更新的实现与验收须同批交付，不默许直接改SQL或替换种子覆盖历史。

### 3.6 G4地点字段与身份

2026-11-15用户决定保留独立“地点名称”，用于识别工作地点，不以详细地址替代。详情的国家/地区、行政区划、详细地址、邮政编码及只读完整地址统一并入“基本资料”，不再设置独立“地址”区块；新建及维护表单沿同一基本资料分组，记录信息仍由共用日期维护区承接。

“完整地址”为只读展示，由所选记录准确采用的行政区划路径按层级顺序连接，再直接连接详细地址；不插入空格、斜线或其他分隔符，不加入国家/地区，不改写名称及详细地址自身的空格、标点和繁简体。例如广西壮族自治区南宁市西乡塘区广西大学宿舍211。澳门无区划链时显示详细地址。新建/维护随已选候选和详细地址实时展示，地址尚未选全时显示“待完善地址”。不新增存储、API输入/输出、独立字段权、筛选或CSV列。

已保存记录的完整地址仅在同时具备geoAreaId、geoAreaPath及addressLine读权时显示；路径或准确采用名称不可读取时显示“地址信息无读取权限”，不得把不完整链当成完整地址，也不得回退当前目录名称。当前详情、历史来源和编辑草稿各自使用已有获权投影；失权时与原地址引用同步清理。新建预览按countryRegionId、geoAreaId及addressLine的输入写权展示，仅拼接当前录入内容与服务端已授权的候选路径；新建表单的字段集合为可写输入，不要求不存在的geoAreaPath写权。

### 3.7 G4完整维护的采用矩阵

本节细化[目录引用资格](#m02-br-205)与[维护规则](#m02-br-211)，适用于预览、保存及能力上下文。先由共同内核形成合法完整候选，再按记录角色及实际差异决定采用；“资料记录”指最终非DEACTIVATE记录。国家与区域稳定ID均相同才算引用不变，重新选择同一个ID不构成手动刷新证据的入口。

| 操作及最终候选变化 | 采用日与准确证据 | 对其他记录的影响 |
| --- | --- | --- |
| 创建 | 按首条生效日新采用 | 首条状态/分类与企业起日沿共用规则 |
| 新增/插入资料，引用不变 | 继承所选位置最终前序的采用日/证据，新增日期不触发重选 | 后继独立资料保持；停用继承由Finalize计算 |
| 新增/插入资料，引用实际变化 | 按新增记录生效日新采用 | 不向后传播独立地址；不得把当前头地址当插入位置基准 |
| 更正资料，日期/分类/引用不变 | 保留目标修订原采用；名称、详细地址或邮编变化不重新核新选资格 | 对合法的后继停用继承传播最终前序资料/证据；独立资料保持 |
| 更正或改日，最终资料记录的日期改变、引用改变或分类改变 | 按最终记录生效日重新采用；包括首条、恢复记录及合法分类转换 | 真正来源前进且仍合格可接受，不比较客户端目录版本；受影响停用继承随最终候选 |
| 新增停用、更正/移动停用、分类更正最终为停用 | 继承最终前序全部资料和准确采用，不在停用日重新选地区；按共用规则限制资料补丁 | 停用日期本身不是新的采用日，不能制造独立停用地址 |
| 新增重新启用 | 按恢复日新采用，即使稳定ID未改；恢复资料为独立快照 | 资格不合格须改合法地区/日期，不擅自复用旧资格 |
| 固定期间创建/插入 | 停用端继承前序；恢复端按恢复日新采用，允许获权资料变化 | 两条与终态同事务，失败零部分事实 |
| 固定期间维护 | 停用端仍继承；恢复端日期/分类/引用实际变化才新采用，其余保留恢复记录证据 | 仅移停用端不强制刷新不变恢复记录；全部共同状态守卫保持 |
| 分类删除或固定期间删除 | 删除后保留下来的独立资料记录沿原证据，派生停用继承最终前序 | 恢复出的连续启用区间不构成新的采用事件；不检查目录持续覆盖整个地点生命期；非法孤立恢复仍由内核拒绝 |

每个需要新采用的最终资料记录分别按自己的生效日解析；同请求相同(国家,区域,采用日)可复用固定事实。先核显式要求及真实引用变化的字段权，再解析资格；Finalize后复核完整差异与授权。不能用隐式删除/继承绕开字段权，也不能把仅来源版本变化误判成用户更换区域。未发生新采用的操作可读取原证据完成内部继承，不因缺目录新选权而失败；对外标签仍按当前权裁剪。

| 列表、导航、选择 | [现有类型端口](../../../apps/web/src/features/organization/dated/list.ts) | 各对象查询投影；首批只有Location接选择/导出；不新造第三种选择协议 |
| 历史存储 | [固定类型生成器](../../../internal/contexts/organization/infra/history/generate/main.go)、当前封存与读取段机制 | 独立类型和SQL；无国家级全量摘要或另一个历史平台 |
| 当前授权 | X03 guard及现有动作/字段目录 | 真实范围事实与目标声明；无额外判权证据表 |
| 地理关系 | Organization对象应用/领域代码 | GeoArea受控父关系、有限链解析和Location引用资格；不导入部门BU归属、全期运营覆盖和Hierarchy表 |

每项扩展必须由本批实际调用方使用。国家无需地址控件，GeoArea无需工作地点字段；Location不因使用区域就获得目录维护权。

## 5 存储与数据装载

### 5.1 独立表组

拟使用organization.country_region_*、organization.geo_area_*、organization.location_*三组明确归属的表。每组独立持有身份/编码、不可变来源、按日成员和修订、类型资料、读取投影、业务事件及提交终态；准确DDL由所属迁移和sqlc源维护，不建立通用object_type加JSON/EAV的混合事实表。

有效期间使用daterange [start,end)，首条/同日/来源前驱/所属对象/封存完整性等沿当前模型的约束模式验证。地区官方码索引包含scheme、region、code及有效期间，防止不同代码体系或历史期间错误碰撞。Location企业内编码与来源映射分别索引。

G3代码及结构固定，实际采用`(instance_id, country_region_id, scheme, code)`身份唯一约束；来源键另按实例与命名空间唯一，完整UUID仍为主身份。代码仅属身份的派生索引必须与不可变初始结构一致，不能成为可单独修改的第二份事实。业务记录仍用daterange，但本批不为不变代码另建期间分段/排斥约束或同码回收流程；未来真实代码修订/复用才实现上段的期间语义并单独验证。

完成标记只保存实例内国家目录或某地区已完成的包版次/摘要，与对象来源映射共同支持发布；不增加共享业务终态或导入作业状态机。三类对象结果仍各自查回。首先使用必要数据库索引和请求内祖先复用，不预建跨请求路径缓存及失效广播；查询投影可重建，不能成为历史唯一存放处。

### 5.2 初始数据与后续来源更新

首条日期由Go默认1900；明确的来源生效日期优先。种子映射固定到本实例UUID并在重试保持；相邻仓目录、Odoo连接和本机路径不进入构建运行依赖。许可、署名和来源摘要随离线资料保存。

固定包转换时一次检查结构/来源/范围/代码，按区域结束时核对数量、映射及拒绝清单，再登记该范围完成；不为凑数量吞掉坏行。逐对象事务仍核当前对象及真实引用，不绕过领域约束。运行中的列表、候选、预览和保存不重复计算全包摘要、重跑全部映射或证明全国目录完整；完整诊断留在装载/离线核验。后续来源更新不覆盖人工显示资料或旧来源，不按名字猜测撤并映射。

### 5.3 G3固定资料装载与发布

区划资料从G0准入包生成独立、可审阅的版本文件，嵌入当前应用；包摘要、源文件及许可随仓保存。国家/父关系映射用完整实例UUID和有命名空间的来源键，区别于可编辑名称及业务代码；首次采用封存当次国家与父链的准确引用。代码方案、原码和区域性质为必要业务分类，提供方名称、原始路径、来源包版次与摘要不扩散到HTTP资源或页面。

装载次序为国家目录已发布→验证该地区固定包→按父先子后逐对象提交→核对全部初始化映射/结构→写入该地区完成标记。四地各自发布，澳门独立版次的加入保留原三地的来源摘要和完成标记。未完成地区的普通列表、详情与候选不暴露部分装载数据，离线装载输出可报告已受理/失败项；其他已完整地区正常使用。澳门目录核对两组共十条后发布，地点地址仍可按基础地址办理。

发布门槛覆盖全部公开对象入口：列表、详情、单日路径、候选、前后导航、日志/准确来源、维护预览和普通写命令。每次在完成当前授权后核对应地区标记，普通写在同一事务内核对；不能只隐藏菜单。context/原因等静态入口可返回当前有权能力及范围状态，不能夹带未发布对象资料。原提交恢复继续按原主体和标识定位，不改变已落库的终态；未发布时只投影允许的提交身份和结果状态，抑制对象/来源/记录、名称、路径等业务投影，发布后才可按当前权限查回。受控装载在应用内查原映射/终态续做，不依赖公开详情，也不接受调用者传入“跳过发布”的开关。

每对象创建沿普通授权、日期和submission事务，不绕过应用直接灌表。内部固定包装载采用父链时核对已提交父与已验证包结构，不要求本地区提前发布，避免初始化循环依赖；普通候选和后续Location采用必须检查地区完成标记，HTTP不得传跳过发布检查的标志。中断/未知提交先按原标识恢复；已受理不得重建身份或来源，明确not_applied后按既有协议续办。并发同包以稳定身份、唯一映射和原提交结果收敛。完成标记提交前检查本地区集合及来源映射，失败仅回滚当前对象或标记事务；已提交行保留供重跑。

完成包重跑核版次标记后直接结束，不逐次重验全国摘要。未完成包续做只比较不可变初始映射和结构，不要求现有显示名称仍等于原始名称，不覆盖人工维护。不同摘要的同版次拒绝；新版本和撤并不借初始化程序自动套用。发布标记的整组核对只发生在装载结束，不进入普通列表、路径、候选或保存请求。

地区最终核对采用一次有界批量读取：本实例/地区的来源键、对象/国家/父身份、代码方案/代码、性质/层级、初始日期及原包绑定，与已验证固定包逐键比较，检查集合相等、无缺项/多项；随后在该事务内原子写标记。对象提交阶段负责各自来源完整性和父采用，不在这里逐行Load完整历史、重复展开祖先或计算全国业务摘要。G3不允许其他结构修改/删除，稳定ID和唯一约束使并发同包收敛；已发布标记同摘要幂等，不同摘要拒绝。覆盖核对失败、标记事务回滚/未知结果和两个装载者同时完成的反例；不以数量相等代替逐键一致。

## 6 API、查询与页面

### 6.1 类型API

国家/api/v1/country-regions、区划/api/v1/geo-areas及G4地点/api/v1/locations均已接通；实际分轮验收范围分别由各批实施记录持有。按第4.1节实际能力接context、列表/详情、原因、维护、日志和原提交恢复；Location另接选择/导出。受控来源工具调用同一应用服务，不要求另开公网导入HTTP API；不存在的功能不预建端点或空DTO，不将Department DTO断言为新对象DTO。

### 6.2 正常菜单和表单

国家/地区与行政区划置于“设置→基础资料”，地点置于“设置→组织配置”；导航分组直接进入列表，不新增工作台或中转页。GeoArea列表标题为“行政区划”，行内显示区域性质、层级、代码、上级、路径及国家/地区；不能把澳门地址分区藏进正式行政区名称中。

按第4.1节能力复用DatedPages、TimelineEditor、共享日期/列表/反馈组件、未保存保护和原结果恢复。地址控件由GeoArea/Location实际需要驱动，不要求国家页接入地址选择器。级联选择只做输入辅助；候选读取或预览不成为额外保存许可，保存事务处理真实资格。获权可编辑字段直接呈现，更正默认原值，识别实际变化后直接保存。

国家/地区详情直接展示编码、显示名称、英文名、电话区号及业务日期/状态，不提供“来源资料”区或source字段权；提供方、数据版次和原码可在仓库版本资料查阅。行政区划保留必要代码方案、性质和层级，不提供提供方来源面板或source字段权；未准入地区的范围说明见第6.3节。内部UUID、封口、正常幂等保证等不成为常驻表单说明。只显示必要候选引用标签，不恢复128已删除的详情关联快捷跳转与专属判权框架。

详细地址按四地适配显示层级名称；简繁原文保持，中英文标签沿项目支持范围，缺译名回落原名不生成假译文。窄屏须同时看清区域层级和父路径，不能只显示一个可能同名的末级名称。

### 6.3 G3查询、候选与页面合同

GeoArea 普通目录按服务端今日查询。国家范围为 CN/HK/MO/TW。国家/地区列以稳定国家 ID 匹配，当前可读名称用于选值和显示；层级列以来源层级键精确匹配。两列使用共享的单列条件，修改列会替换已应用的单列条件。直接上级、关键词、状态、排序和分页与列条件共同作用。普通目录涵盖全部层级，有 parentAreaId 时仅列出该上级的直接下级。「仅根层」已取消，普通列表和对象导航拒绝 rootOnly。地点逐级候选的起点与末级资格继续使用既有来源父关系。

列表页使用20/50/100条有界分页，名称/代码检索、状态和排序沿既有文字/列表规则；过滤和排序只消费有权字段。列表、返回上下文和前后导航共享完整GeoAreaQuery及排序，不把国家/上级/层级挤进旧的单列SelectionQuery，也不借机建立选择草稿。前端现有NavigationPort已接URLSearchParams，GeoArea适配器保留全部条件，Go增加本对象强类型导航输入即可；锚点不在当前结果时返回空邻居，不跨范围寻找。导航按锚点和顺序窄查相邻项，不复制国家Navigate从第一页遍历至锚点的实现。

桌面从「国家/地区」或「层级」表头的列菜单筛选。窄屏从摘要行的国家名称或层级值打开同一列条件；首次打开带入该行的值，已有同列条件时带入已应用值。空结果时可从已应用摘要修改或清除。编辑只改草稿，「应用」连同当前关键词提交并回第一页，取消和 Escape 保留已应用条件。上方只保留共享控制区与已应用摘要。「更多操作」沿用共享入口。

清除上级范围是导航动作，只使用已应用条件。查看下级从获权的列表行进入，显示「某对象的直接下级」，清除父列表的关键词、层级及其他仅匹配父行的列条件，保留已应用的国家条件、状态、排序及页大小，从第一页开始。新开的下级范围保存原已应用查询、原页和触发行；逐层返回恢复对应查询与位置，返回详情的来源列表仍定位子行。复制或刷新有来源的地址也能返回；无来源的直接入口可清除上级范围。父标签失权时清理名称，结果为空显示「当前范围没有可显示的直接下级」。服务端读取失败使用错误及重试。

基本资料用标准标签和值展示性质、层级、代码方案、获权国家/地区和可换行的完整路径（国家/地区、祖先、本级）；保留路径日期及原采用路径语义。详情 countryRegionName 由 Go 按国家引用和名称读权投影。本级使用所选记录及其可读名称，无权读取本级名称或任一段时省略完整路径。有权的国家名称仍可独立显示；显式来源按原采用及当前权限解析。目录结构仅供读取。

路径由Go返回单日所需祖先链和pathDate，页面可换行展示；显式sourceVersion读取原采用链并返回adoptionDate，不再夹带会随最新目录变化的“当前路径”。历史和当前视图分开，受限父标签不由缓存或最新名称补齐。

| 拟定资源/端口 | 输入与输出合同 | G3边界 |
| --- | --- | --- |

国家、区域及必要祖先在采用日均须有效、启用且有第7.2节规定的当前读权；缺失、不可见、跨地区父返回不暴露被拒对象的错误，停用/日期不合格的父返回不可选状态，不静默改成根范围。adoptionDate由办理上下文提供，后续Location保存从实际命令确定该日；用户不填写第二日期字段，传候选日期不改变保存资格。

候选默认20条，可选50/100，按代码字符串及稳定ID排序，要求相应代码读权；query去首尾空白、上限200码点，名称包含/代码匹配只使用有权的相应字段。采用“取得pageSize条合格项再看一条”的分页方式；没有精确总数。首请求无cursor，后续使用不透明防篡改游标，不支持跳页；游标绑定实例、主体/会话、国家与GeoArea两类当前授权/字段范围、服务端判权今日、国家、采用日、父、标准化查询与页大小。X03 在本页短事务内持共享锁提供主体的策略版本，游标同时绑定该版本。绑定的查询条件或服务端判权日变化时，旧游标失效。策略变更后即使恢复原授权集合，旧游标也返回 409 M02_CURSOR_CHANGED；地点选择器清除已加载项，用原查询条件从首页重新读取。失去必要读权时返回 403 ACCESS_DENIED 并清除候选。游标锚定最后返回项的不可改代码/ID，过滤/前瞻不吞掉下一合格项；空结果且无后续时hasMore=false且无cursor。

每请求以一个读取快照取得必要资料，Go按当前授权及采用日投影，足量后停止，不先算整树/全匹配数。相关存储和授权失败原样失败，不能把超时当空页。跨页实时读取不承诺冻结集合；期间名称/状态变化可能改变下一页成员，刷新从首页重查。该边界不影响保存锁内重验，也不需要全国版本。普通目录不用候选过滤：目录仍能查询有权的非末级和停用对象。

“最具体”以完整已发布结构的真实末节点判定，与状态/日期/权限过滤分离。G0大陆四个地市末节点东莞441900、中山442000、儋州460400、嘉峪关620200可最终选用；其余大陆末级为区县，香港为18区、台湾为368乡镇市区。下级全部停用或失权时，不把上级升级成末级；只返回有权分支及可用条目，不暴露被拒对象的身份、名称或数量。普通目录仍可查阅获权的非末级和停用对象；目录查询与新选资格是不同任务。

澳门候选返回明确的基础地址模式与空条目，不伪报目录故障或完整区域发布；CN/HK/TW未完成装载须明确未就绪，不能同样解释为可省略区域。基础地址模式仍须核国家目录发布、采用日事实/启用状态及对应当前/历史读权，不能跳过停用或失权国家。没有区域引用时不要求不存在的GeoArea节点字段或历史权；G3目录菜单/资源本身的GeoArea.read保持，G4基础地址新采用只消费国家引用。G4据此处理澳门可空与其他地区必选；G3正常目录只说明尚无已准入区域，不常驻展示内部导入机制或隔离清单。

最具体判断使用完整已发布结构的有索引子边存在查询或等价的可重建投影，不对每个候选递归遍历整棵地区树。路径读取只走当前请求需要的有限祖先，并核归属/循环异常；数据损坏返回错误，不从旧缓存拼造链。

名称和英文名维护直接显示有权字段并保留原值，结构资料只读；原因采用现有Go默认。详情保留业务记录/操作日志及确切sourceVersion读取，不增加提供方来源区、origin DTO、source字段权或详情关联跳转专属授权。版次/提供方核查在仓库资料完成。

### 6.4 G4查询、选择、导出与地址控件

2026-11-15用户明确简化地点列表：名称之后默认显示“国家/地区”列，移除独立国家/地区搜索框，保持共用列表控制区。该列显示记录准确采用的国家名称，由列表响应countryName提供并遵循地点字段、国家当前/历史读权；不以国家ID或目录现名替代。只补展示列，不增加专属菜单、弹窗或筛选组件。实际实施与验证见[地点整改第7节](../../verification/204-location-region-picker.md#7-地点列表国家地区列简化)。

Location选择复用部门的固定身份草稿/增量修订机制，并有独立类型、表与路由。start捕获当前获权完整匹配身份，支持显式少量选择及全结果；resolve按原draftId/revision编辑或核验。草稿绑定实例、企业、主体/会话、判权今日、规范集合条件和当时授权上下文；页码/页大小/排序变化保持成员。集合条件、判权今日或绑定授权失效后拒绝旧选择，只有用户主动start才重捕获。普通资料变化导致对象移出原查询但仍有读权时，已捕获成员保持；新匹配对象不补入。导出时重验当前入选身份及全部必要字段权，缺失/失权整笔拒绝；已排除对象不因不可读而阻止剩余集合。前后导航仍按当前查询，与固定选择集合分开。

失败处理继承301：首次start未知不自动重发；已有草稿纯读取暂时失败保留意图、暂停导出并按原身份核验；编辑丢响应不能盲重放或假定revision未推进。固定身份数量、增量批次和资源限制复用现有Go机制，至少能完成10000地点全选；不得在客户端设置更小业务上限。实施时如抽取共用小函数，BU的集合协议保持其原合同。

CSV固定九列、顺序为编码、名称、英文名、国家/地区、行政区划路径、详细地址、邮编、状态、生效日期。与列表/详情使用相同地点记录及准确采用标签，排序按导出请求的获权排序及稳定ID；空可选项为空单元格，MO路径为空，邮编作为原字符串输出。复用现有UTF-8/BOM、CSV引号/换行转义及单元格安全处理；完整解析后逐值核验，不以电子表格软件的自动数值转换反改原邮编。各列必需权限见7.5；先完成全部行及字段核验再向浏览器交付文件，任意末项损坏或失权均不生成成功下载。实现复用既有私有临时文件、限额、取消和断开清理机制，不在内存无界堆积全文；网络传输中断不得被前端当成完整文件。

地址控件直接呈现国家、最具体区域、详细地址及可选字段。国家候选由地点上下文返回四地有权范围；CN/HK/TW调用G3分层/搜索候选，MO只处理国家基础地址，不调用要求GeoArea.read的目录入口。为避免前端推算改日/分类/固定期间，地点只读reference-context接收与当前维护相同的目标/位置、拟分类/日期及引用补丁，Go按3.7返回是否适用新选、采用日及获权范围；未选原因按现有只读投影规则允许，仍不可用于Persist。读取仅需维护所需信息，不因原因未选伪造原因或可保存候选。尚未选完区域时reference-context仍可返回有权国家与采用日，不要求提交一个已有合法末节点才允许查询候选；不变引用的无关修改不以该辅助读取成功为保存前置。使用返回的采用日查询候选，保存再次从完整命令计算；两者都不产生保存许可。用户改相关输入时清理旧游标/候选并取消读取，晚到结果不能覆盖新国家、日期或动作。

## 7 事务、权限与历史保护

### 7.1 M02-BR-209 最小依赖与并发

目标对象继续核对expectedSourceVersion；目录引用只提交稳定ID，除目标本身外，不要求用户为每个祖先带期望来源版本。新采用引用在写事务锁内读取最新必要事实、核资格并封存实际采用来源；若目录只更名且仍合格，可保存并采用锁内资料。真正停选、跨地区、缺失、失权等才拒绝，错误定位对应字段；不把任意引用版本前进当作用户必须重选的理由。

| 变化或请求 | 必要读取和校验 | 不做的工作 |
| --- | --- | --- |
| Location纯名称、门牌或邮编变化，引用采用不变 | 目标、当前授权、已有准确引用；字段和最终候选 | 不重验目录新选资格，不扫描地区或已有地点 |
| Location按3.7判定的新采用（创建、换引用、资料改日、新恢复等） | 目标、本次国家/区域及有限祖先链；当前资格、实际日期、完成版次 | 不加载全国或祖先全部历史；单日采用不校验整个地点生命期 |
| CountryRegion/GeoArea显示名称更正 | 目标、授权、共用候选；自身来源/引用保持 | 不枚举后代/地点，不刷新它们的来源 |
| 目录停止/恢复选用 | 自身时间线及必要状态锁 | 不级联停用子节点或旧地点，不回查所有旧消费者 |
| GeoArea国家、父、层级或结构覆盖日期改变 | 原新范围守卫、必要祖先和真实受影响入边/期间；无环及父资格 | 不把所有名称修改也走结构闭包，不以全国锁代替关系判断 |

初次准备与持锁后检查的事实可能变化，因此后者必须保留；每个请求内复用已固定的候选、授权投影和引用解析；预览与保存共用准备函数，保存按锁后实际变化重验，持久化只校验类型/归属/存储结构，不重算同一业务候选。只读候选分页按足够合格项停止，写入使用锁内事实，不把候选缓存当许可。

结构写沿本国家/地区关系守卫及必要头行的固定锁序，只有结构变化获取相应排他守卫。覆盖双向改父成环、零入边与并发新增、父首日变化与新建子。目录状态写与新地点采用必须锁同一目录头/状态事实，并按既有锁序交接：先采用成功后停选时旧地点保留；先停选提交后新采用拒绝。两者不属于“任何顺序都只能成功一个”的关系持续覆盖约束。

事务取消、DB异常及未知COMMIT继续走既有submission恢复，零部分对象事实；批量装载的多事务边界按2.3节登记。不增加通用依赖版本、重试循环、预览许可或判权档案。

### 7.2 M02-BR-210 当前授权和隔离

国家/地区与区划使用实例目录范围，地点使用企业范围；不伪造管理BU以复用部门授权。各对象read、history.read及实际开放的create/维护动作分别授予；只有Location首批具有export，受控来源装载复用明确授予的领域动作/字段权，不因CLI绕过授权。字段权与动作权同时核验。普通管理员默认是否具有来源装载权由开发最小角色配置显式声明，不能从用户角色名称推定。

读取失败/撤权先裁剪旧标签、路径、预览及缓存；当前授权继续约束历史。目录关系可用性不是权限，来源包完整性也不是授权凭证。三类pending submission、路由和终态命名空间隔离，并保留现有BU、部门原提交恢复。

G3授权目标仍为实例目录，复用现有read、history.read、create及实际维护动作；不新增节点ACL、路径专属动作或判权证据表。GeoArea字段目录包括code、scheme、nature、level、name、nameEn、countryRegionId、parentAreaId、geoAreaPath、state、effectiveDate、operationType、operationReason；geoAreaPath仅为派生展示字段，不可写。结构字段写权只供固定包create，普通维护动作不接受它们；来源维护者另外明确获得初始化及所需读取权，普通维护权不能推导为create权。

| G3读取/使用场景 | 当前授权及字段投影 |
| --- | --- |
| 当前普通行和当日路径 | 自身GeoArea.read；显示国家标签另核Country.read及对应字段，父/祖先标签核GeoArea.read及其字段；关系ID受countryRegionId/parentAreaId控制，完整路径另需geoAreaPath。一个字段权不能放大另一个对象的读权 |

| 显式sourceVersion及准确采用链标签 | 自身准确来源需自身read与history.read；每个被引用对象的准确来源标签分别核该类型的read与history.read及字段交集。不能只核子节点history或用当前标签替代旧值；无权部分省略身份/标签，路径标为受限，不呈现残缺链为完整路径 |

业务日志记录操作者摘要、操作、前后资料及准确来源；不重新引入128删除的逐次完整授权过程持久化。

### 7.3 M02-BR-211 维护、撤销和身份处置

未保存表单取消不写入。第4.1节开放的各动作沿共用规则；Location保留新增/插入、更正、改日、分类删除、单条启停及固定期间，目录高级修订仅由有依据的受控来源入口办理。首条不可删除，普通更正不得变对象类型；目录普通用户不得借字段更正伪造官方实体。

### 7.4 G3锁与G4采用交接

新采用在当前事务内按国家→区域祖先从根到叶→目标节点固定顺序以共享行锁锁定必要目录头（状态写取冲突的排他锁），读锁内的状态、单日资料与授权，保存准确引用；多个同级身份需要加锁时按稳定ID排序。目录停止/恢复选用也锁其自身相同头行，不另开一套资格锁。G3结构在发布后固定，不需要为每次候选或名称更新获取国家级排他关系锁。

若仅名称更正先提交，新采用可取锁内新名称/来源并成功；若新采用先完成再停选，旧采用仍有效；若停选先提交，新采用拒绝。读候选不持锁跨请求，不返回需客户端保存的引用版本许可。目标本身的expectedSourceVersion、当前字段/动作权限和提交终态保护保持。

G3的真实DB端口检查须覆盖上述顺序及完整链输出。G4接入同一事务时再验证地点持久来源、日期重选、旧地址无关修改和未知提交恢复；不能以G3的内存结果或端口测试称Location已交付。未变引用沿用原证据，不因为其祖先当前名称或状态改变而自动刷新。

### 7.5 G4地点授权和准确地址投影

Location动作包括read、history.read、create、record.add/correct/delete/redate、deactivate/reactivate、lifecycle_pair及export，实际名称沿现有动作目录逐一映射；不新增部门reassign或目录create依赖。字段目录为code、name、nameEn、countryRegionId、geoAreaId、addressLine、postalCode、geoAreaPath、effectiveDate、status、operationType、operationReason；adoptionDate随有权引用日期投影，内部准确链不可写。完整Grant及字段交集沿X03，不拼接多个不足的Grant来虚构授权。

| 任务 | 权限与失败边界 |
| --- | --- |
| 地点普通资料/当前记录 | location.read及字段；选择非今日recordId时另核location.history.read并取字段交集；显式sourceVersion始终要求history.read |

| 不变引用的无关资料修改 | 仍核地点本身读/写及共用历史维护要求；原证据内部继承，不重新要求目录新选资格或所有目录字段权；已失权标签不得因成功保存恢复显示 |
| 隐式变化、继承和删除 | 初始显式输入及最终真实差异都按现有维护授权检查；隐式改变国家/区域稳定ID不能绕过相应字段写权。纯准确版本变化不追加虚构reassign；停用继承与派生变化遵循共同动作/字段检查，身份及权限错误不泄露目录资格细节 |
| 选择/CSV | 地点read与export及九列全部必要字段；国家标签核准确国家read/history/name，非MO区域完整路径核准确GeoArea read/history及链字段。任一必需列/入选对象无权整笔拒绝，不以空值伪装真实数据；MO空路径不要求GeoArea读权。地点当前记录导出不额外要求地点history，目录准确标签仍需其历史读权 |
| 日志/摘要/恢复 | 操作者摘要沿当前所选记录读权，日志/准确源另需历史权；日志前后地址各按保存证据裁剪。恢复另核原主体/类型/提交身份及当前读权，终态原件保持，仅响应投影；不得把已保存终态变成重新执行 |

国家/区域无权时，地点自己的获权门牌、名称等可以继续显示；路径受限不等于整个地点不存在。目录权限系统异常、必要来源损坏与明确无权分别处理：前者返回读取故障，不能冒充空地址或新选不合格。当前读权撤回立即裁剪列表、表单、历史、候选、预览及返回缓存；403后503/断连不复活旧标签。保存结果未知仍按301保留本人待确认身份；账号切换不保留业务正文。

### 7.6 G4同事务接入与锁序

G4已将GeoArea引用方法提取为ReferenceUnit，并由Location在原pgx事务上提供目录窄适配；只复用实际只读/共享锁方法，不创建嵌套事务、不提供假的GeoArea写方法。若现有Unit过宽，在真实消费者接入时提取仅含引用所需方法的有类型接口，原G3同时编译/回归；不先建设通用多对象仓储。MO用同事务国家采用端口，核国家发布、采用日、状态/当前权，封存国家准确修订；不调用要求GeoArea菜单权的HTTP入口。

锁顺序在既有X03策略守卫、submission/目标Location写锁之后，对所有新采用所需目录头取共享锁：先国家按稳定ID排序，再每个国家中根到叶的层级、同层稳定ID排序。多记录/跨国家候选先去重确定有限并集再依序锁定，不能按动作出现顺序交叉加锁。国家/区划状态或名称写锁自身同一头，且不反向取Location锁；G3固定结构不新增国家排他关系守卫。实际锁键/预算在T00对照现有代码登记，两阶段发现及持锁核验沿同一取消预算，不复用离线导入扩展预算。

锁内验证客户端国家ID与最终区域的国家一致、地区发布、真实末级、日期/状态及当前授权，再保存该日的国家和根至最终节点准确来源/recordId/revision。国别不匹配不得由解析器根据区域自动覆盖国家。仅更名可用锁内新资料成功；先采用后停选可均成功，先停选后采用拒绝。不变采用仅核已有准确引用的内部完整性，不按目录当前头重捕获。

地点来源、修订/成员、查询投影、业务事件/日志及提交结果在同一事务保存点内发布。预览与保存共用准备/采用判定，保存持锁后重验，不接受客户端预览结果或目录版本许可。未知COMMIT不换号重发，使用既有submission确认；取消/DB故障不得留下半链、孤立事实或伪成功终态。独立SQL约束保护类型、归属、完整性及原子性，业务资格仍由Go唯一裁决。
