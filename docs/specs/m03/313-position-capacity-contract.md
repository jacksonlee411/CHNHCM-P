# CHNHCM-313 编制管理合同

首批交付 HR 后台定额与分配。有权 HR 可只给部门定总额、只给岗位定额，或在已定部门总额内给岗位分配名额。在同一入口直接保存生效日、额度和原因。招聘预留、任职占编及人员入转离按后续批次接入。[部门定义](../m02/118-department-business-requirements.md) · [岗位定义](312-position-contract.md) · [315 后台实施计划](../../archive/plans/315-staffing-quota-administration.md) · [方案复核](../../verification/315-staffing-quota-administration-review.md) · [登记表](../../governance/registry.json)

## 1 核编范围与交付顺序

M03 首批的实现、实测日期样例及后续消费者的验收边界见[岗位核编实施验证](../../verification/313-quota-implementation.md)。

| 批次 | 正常业务和责任 | 可验收的出口 |
| --- | --- | --- |
| 本期 M03 核定与调剂 | HR 从「设置 → 职务配置 → 岗位 → 岗位编制」核定、增减、更正单岗额度。从「部门编制分配」查看部门统计、设定总额或同日调整多岗。只读者按权限查询 | 部门核定总额、岗位定额与合计、待分配编制，以及按日期可查的历史。保存即按所填日期生效 |
| 后续 M05 招聘 | 招聘从真实需求发布、寻访、预留、换人或释放，在发出正式录用时落实本份名额 | 招聘进度与预留分开查询。使用某份任职将释放的名额时须有人事来源 |
| 后续 M04 任职与跨域联验 | 人事从工作关系办理入转离、兼岗、两岗接替及撤改，从原录用办理入职 | 任职占编、实际人数及各岗位交接。招聘与任职用量核齐后可查完整可用编制 |

M02 提供企业内部门身份和有效日期，312 提供岗位按日唯一的直接所属部门。两类额度均由 M03 维护。只有部门时可直接核总额，只有岗位定额时可直接按岗维护。后来补定部门总额时一并核对已有分配。HR 直接选择要维护的对象，无须配置控编模式。

人员编制计划（WorkforcePlan）承载期间目标和预算。已有计划时，管理员可明确采用相应计划版本，另作有生效日的核编或调编。首批可直接核编。占编规则的维护随首个招聘或人事消费者接入，核编不依赖预先配置规则。薪酬金额、约定工时、排班及考勤由各自领域按实际业务维护。

本期减编以已经登记的额度和岗位归属为依据，逐段校验[部门分配](#m03-br-040)。存量岗位也可调减定额，HR 无须先登记员工、盘点实占或取得审批单。此前“部门只作岗位小计”和“首批减编先核齐人员及招聘用量”的范围由本期约定替代。[原范围复核](../../verification/313-hr-staffing-review.md)

后续接入真实预留或任职时，对已接管的岗位和期间同时保护原承诺，按[使用来源验收](#m03-ac-095)核验减编、撤编、停岗及改日等同等收紧。对应业务域提供存量和未来安排、覆盖期间与来源版本，受控新岗可由设岗及接管事实确认零起点。用量未知时，寻访可继续，依赖该段用量的承诺须待核实。DB 空表和部门待分配数均不能证明可招人数。

## 2 M03-BR-025 编制单位与占编口径

| 名称 | 指定业务日的含义 |
| --- | --- |
| 部门核定总额 | HR 直接给指定部门核定的常规整数上限。未核定时仍可设岗位定额。明确核为 0 时该日可分配数为 0 |
| 岗位定额 | HR 给某一岗位核定的常规整数。一个岗位可有多编。核为 0、当日未核定（含首次核定在未来）、字段受限分别呈现 |
| 岗位核定合计 | 合计该业务日启用且直接归属本部门的岗位定额。仅统计本级，停用岗定额留在该岗历史与明细。未核编岗另计岗数。完整范围内没有已定名额时分配按 0 算 |
| 待分配编制 | 已核部门的总额减岗位核定合计，可保留至以后分配。部门未核总额时该项留空。仅有部分岗位或字段读权时只列“可见范围”小计，完整合计、待分配数及可反推受限数值的提示按权裁剪 |
| 交接名额 | 同一岗位在指定期间供一名接替者与原任并岗的专用名额。招聘以需求的单人份额为依据，内部接任以人事调动及接任任职为依据。按日单列授权数和其中已预留、已占的份数，到期结束 |
| 已占编制 | 当日按规则占编的有效任职数，每份占 1，免占编任职占 0。分别列出计入常规的份数（含已核实的超额）和由交接名额覆盖的份数，两项合计为实际已占 |
| 招聘预留 | 真实需求中仍有效、尚未转任职的单人名额，分别列出常规和交接部分。同一份额同一天最多预留或占用 1 个名额 |
| 空编、可用编制 | 启用且已核编的岗位，常规空编为核定数减常规已占，常规可用为核定数减常规已占和常规预留，两者最低均为 0。超出的实际人数和承诺缺口另列，见[交接差额](#m03-br-036)。其他需求只能使用常规可用。岗位启停及补员状态另列 |
| 在岗人数、任职数 | M04 在选定范围内按人员身份去重统计在岗人数，按有效任职身份统计任职数。跨部门汇总人数时在汇总范围重新去重。对外统计按报告制度另取数 |

交接、已占、预留、空编、可用以及在岗人数属于后续使用口径。同一岗位有两位各承担部分工作的人员，两份任职都占编就需两个完整名额。有权者按企业、人员类别、用途和有效期间直接维护规则。按岗位任职（PositionManaged）全期间须有有效岗位，可占编或免占编。仅按职务任职（JobOnly）使用有效职务与组织。劳务派遣等类别也依明示规则。

新预留或任职逐段采用唯一适用的规则版本，缺失或歧义时整笔拒绝。岗位免占编、仅按职务两类均不作招聘预留或任职占编。已办理的预留和任职按保存时各段采用的版本核算，后来发布规则不自动改数。要改变既有安排的人员类别、用途、岗位、模式或占编性质，须明确变更生效日，按新规则重验受影响段并同笔调整相应名额。失败保留原采用和余量。

首次核定和增减编录入新的非负整数。显式撤去部门总额，自生效日起该部门可按岗位独立定额，原岗位定额继续有效。撤去岗位定额只结束该岗核定。再次核定沿用原对象的额度身份及历史。后续接入用量时，新增承诺按期取得足额名额，调减岗位定额须覆盖各段常规占编与预留（含交接后的承诺），撤去岗位定额须核实其使用和交接已结束。

<a id="m03-br-028"></a>
### 2.1 M03-BR-028 正式内部兼岗

同一用人单位、同一有效工作关系下，员工可依据正式任命在重叠期间承担不同岗位，可跨部门。人事从该关系新增、变更或结束次任职，记录任命依据、用途、生效日及已确定的结束边界。按已采用用途判断兼岗是否另占 1 个编制。原主岗占 1、兼岗免占编时合计占 1，兼岗另占编时合计占 2。两种情形均为 1 人、2 份任职。变更主次只改变相应用途的主选择。

资格须覆盖全部任期。同人同关系同岗在同一期间只允许一份有效任职，相邻任期可在同一日期边界交接。确定的终结边界才释放名额。临时代办、代签和项目协作按任务或授权办理。主选择、用工主体及合同变更依据按 [M04 关系与任职](../../architecture/target/modules/m04.md)和[大陆用工主体约定](../../adr/009-mainland-organization-terms.md)办理。

## 3 M03-BR-026 核编日期、直接办理与历史

有权管理员输入核定编制、生效日期和调整原因，保存即登记，按业务日生效。未来增减编可提前安排。同日更正从原值带入，保留旧修订。未保存可取消，已生效的错误走更正或规定的日期维护动作。编制管理的核编、调编、预留、释放、占编及暂停补员均由有权人直接办理。授权、服务端业务校验和留痕在保存时完成，无申请单、审批人、流转状态或审批回执依赖。

每企业按对象类型及稳定身份分别维护一条额度时间线。部门与岗位各自一日一节点，数据库使用左闭右开日期段。追加或插入只影响到下一个独立节点。移日、删除非首条、追溯更正须复核全部受影响段。首条可更正、在原次序内改日。首次默认 1900-01-01，可显式修改，核定日须在所选对象启用范围内。默认日过早时指出可用日期，部门或岗位首日后移跨过既有核编节点须先处理早期配置。[日期维护](../m02/120-dated-maintenance-technical-contract.md) · [首次日期](../../adr/202-master-data-default-effective-date.md)

部门或岗位停用时保留额度及未来独立节点。部门停用期间只查额度记录，岗位停用期间退出分配合计，恢复时按当日定额及归属重新校验。岗位与部门各自的有效期及引用保护照常执行。后续停岗还须核清该段预留、占编和全部岗位任职，含免占编任职。记录按 businessAt 定位业务日，sourceVersion 指定准确核编版本，adoptedRef 固定实际采用。日志保留操作者、原因、变更前后和原始记录时刻，按北京时间显示。[岗位定义](312-position-contract.md) · [日期表达](../../adr/026-date-display-and-input-format.md)

<a id="m03-br-040"></a>
### 3.1 M03-BR-040 部门分配与同日调剂

部门已核总额时，任一生效段的直属启用岗位定额合计须小于或等于该总额。未核总额时，岗位仍可分别核定。HR 从部门明细输入生效日、一次调整原因，以及要改的部门总额或岗位新定额。岗位归属由系统带出。只改一岗也可从岗位入口保存。调剂时只填写有变化的行，各行使用同一日期和原因，按调整后的最终分配一次保存。修改岗位定额需要该岗写权，同时修改部门总额时还需要部门额度写权。

Go 对变动覆盖的全部期间复算，包括已知的后续额度节点、岗位启停及改隶日期。岗位改隶从生效日起按转出、转入部门分别核验。岗位资料维护与核编入口共同保护此规则。超额时向有权者指出第一个超额的部门、期间及差额。经办人可调整分配或在权限内一并调整总额。服务端始终用完整分配校验，对受限者只提示可披露的冲突。任一行冲突、失权或写入失败均保留整笔原安排，重送查回同一次结果。

部门编制详情按统计日显示整份分配。时间轴列出获权的部门总额生效日、直属启用岗位的独立额度生效日，以及岗位加入或退出本级分配的日期。转出和转入部门各按本级归属计算。两岗等额对调也算变化，同日合为一个日期。同日更正保留原额度记录。岗位更名、停用期间的单岗调编只改变相应岗位资料。Go 按当前对象、历史及字段读权给出日期。只可见部分岗位时只展示获权变化和小计。部门尚无额度或岗位时仍可查看指定日。

从列表进入继承统计日，直接进入按服务端今日查询。点选时间轴节点后，总额、岗位合计、未核编岗数、待分配及岗位明细一起按该日重读。「查看指定日」可定位到任一可读业务日，查询本身不产生生效记录。调整编制按办理日重读原值。部门或当日可见岗位已有额度安排时默认当前所查日，首次核定默认 1900-01-01。更正、改日、删除非首条分别定位具体的额度记录。岗位行可进入对应岗位编制，返回保留部门和统计日。「变更日志」按确切来源打开当次总额原件。

## 4 M03-BR-027 招聘预留与任职占编

本节及各小节适用于招聘或人事接入后的岗位用量办理，独立于本期后台额度的交付与验收。

Go 按岗位启停、补员状态、常规编制、交接期间、占编政策、预留及任职的全部有效边界逐段复核。预览使用当时数据，保存时重读。安排直接入职时按规则取得可用的常规名额。调岗按新旧任职各自的占编规则同笔释放和取得名额。未来离职到生效日释放当日名额，确定的结束边界可供今天安排未来招聘。拟延期或撤销未来终结须重新取得恢复期间名额。拟议安排有冲突时整笔拒绝并保留原记录，向有权者指出受影响期间和缺额。已经到岗或实际交接延期的补录、更正见[履职事实与差额](#m03-br-036)。

M05 逐份记录名额采用的需求版本、岗位、期间、规则和办理结果。只改需求说明时沿用原预留。换候选时沿用名额，旧绑定和交接失效。缩招、撤销、释放或到期只结束相应份额未用的预留。此前的使用、已转换的任职及历次绑定可查。

招聘在原需求上改拟招总人数。同岗、同期间、同规则、预留情况相同的普通空缺，均未绑定候选人、未作对外承诺且没有指定接替者时，可按人数缩减。可互换的空缺足够且去留无业务差异时，Go 按稳定顺序选足份额，同笔保存新人数、结束的份额及其未用预留。需要在不同安排之间取舍时，只列需要选择的名额，选定并保存后才调整人数。已发录用按双方确认的结果处理，已转为任职的名额由原人事业务维护。

直接入职由 M04 按人事依据办理。经招聘的候选人接受录用且交接资料齐备后，录用自动出现在获权人事的入职入口。人事核实身份和实际到岗安排，一次保存。M04 核对有效份额、候选绑定、录用及交接版本，招聘自动取得办理结果。资料后补齐时沿用同一份录用。入职日须与约定到岗日一致，改期走原录用调整。实际人员类别、岗位、用途、模式及各段规则须与约定相符。全程免占编或仅按职务也可交接。条件失配时保留仍有效的预留，按实际条件调整后再办。

占编逐段核对。同一份额可覆盖一段免占和一段占编。原约定期间内的占编段须有本份额的有效预留，与任期相交的部分从相交首日起等额转换。免占段无需预留。入职日前保留原预留历史，结束该份额尚余的未来预留，短任期结束后不再占编。超出原承诺的占编段按适用规则取得可用名额。全期间同笔成功或拒绝。若本应使用的份额已释放、已失效或已转任，不得改成直接入职来消费该旧交接。同一交接或业务身份更换提交号也只成立一次入职，重复办理仍可查回原任职。

人事在生效前撤销未来首次入职时，同笔撤销该次占编。入职日前的预留和原转换仍可查。若仍需补人，招聘可在原需求份额下从原入职日或更晚重新预留。重送旧办理只返回原结果。工作关系、首任职和主选择的撤销条件见 [M04 用工与任职合同](../../architecture/target/modules/m04.md)。

最后一编同时被招聘或人事使用时，只能有一方取得。保存以当前有效的份额、绑定和岗位用量为准，名额与相关任职一起生效，失败保留原安排。事务顺序和并发保护见[共同事务合同](../../architecture/target/10-ddd-and-state-contracts.md#staffing-quota-transaction)。

<a id="m03-br-029"></a>
### 4.1 M03-BR-029 暂停与恢复补员

招聘预留或任职占编接入后，有权管理员在岗位详情填写暂停或恢复的日期、原因，直接保存。暂停独立于岗位启停及核定数，尚未核编也可暂停。暂停期间仍可发布需求、寻访和面试。拟在暂停期间新增预留、交接名额、直接入职、调入或兼岗时拒绝，包括免占编的岗位任职。仅按职务任职依其自身规则办理。用量核齐时，岗位分别显示余额和补员状态，例如“可用 1，暂停补员”。

暂停登记前已落实的预留或任职可在原岗位、原份额、原期间履行、减量或结束。候选人在暂停登记前已接受正式录用，且本人绑定仍有效的，资料齐备后由人事从原录用按约定到岗日办理一次。占编段转换本份有效预留，免占编段直接登记任职。补齐资料可在暂停后完成。换人或换岗须按新的安排核验，延长部分遇暂停则保留原安排。保存暂停时，对经办人有权查看的待报到录用，提示哪些可按约履行。如需改期或取消，由招聘与候选人商定后从原录用办理。

<a id="m03-br-034"></a>
### 4.2 M03-BR-034 提前补招与到岗承诺

用人部门提出补缺，招聘人员在「招聘 → 招聘需求」登记岗位、人数和补缺依据。已有原单时直接引用相应依据，提前预留和发录用沿用同一来源。寻访和录用草稿中可写预计日期、范围或待定。拟用原员工腾出的名额时，引用人事已登记的该岗最后在岗日及其来源版本。招聘对外发布内容保护被接替人的身份和离任依据。

| 业务节点 | 招聘和人事怎样办理 | 岗位台账怎样反映 |
| --- | --- | --- |
| 预计有人离开 | 依现有招聘权限发布需求、收简历、面试、准备录用草稿。当前满编、离职日未定或用量待核时均可进行 | 招聘进度和名额状态分别显示，例如“面试中，尚未预留”。原任职继续占编 |
| 确定原岗离任日期 | 引用确定原岗占用结束的离任或调动版本，今天即可为计划到岗日起的期间办理预留。若另有已核实的空编，可直接使用 | 原员工最后在岗日仍占编，次日起的空缺可被一份需求预留。两份需求可以同时寻访，同一未来余量只能承诺一次 |
| 发出正式录用 | 招聘与候选人确定一个到岗日。点击“发出录用”一次，沿用本份有效预留。有权新增预留时，同笔补足占编段并发出。免占编段核对资格和补员状态 | 按绑定、岗位、用途及全部承诺期间核验。缺额、缺相应权限或保存失败时保留草稿及原有效预留。需要提前锁定名额或分权办理时，有权人仍可在需求上独立预留 |
| 办理实际入职 | 人事从已接受且资料齐备的录用一次保存，占编段转换本份预留，免占编段直接登记任职。超出承诺期间的用量须另行核实 | 同一名额当日只计一次。入职失败保留原预留，重办可查回原结果 |

开放任期须核对已知的未来变更，直到最后一个开放段。正式录用改期时，招聘与候选人确定新日期，从原录用一并调整受影响的预留。换人、释放或缩减已有承诺时同样核对有效录用。调整失败保留原录用和预留，重办可查回原结果。

<a id="m03-br-035"></a>
### 4.3 M03-BR-035 新旧员工限期交接

两人交接时分别登记真实任职。优先使用该岗的常规余量。两份任职都占编且重叠期间缺一编时，有交接办理权的 HR 可在原招聘份额或[人事调动](#m03-br-038)中直接安排。选定同企业、同岗位的被接替任职后，表单带入已确定的原任最后在岗日、接替者到岗日及补缺或调动依据。保存本次起止日，系统记录办理人，供这一位接替者在缺口段使用 1 个名额。

以财务主管常规定编 1 人为例，接任者计划于 2027-03-22 到岗，原主管最后在岗日为 2027-03-31。HR 可在到岗前一次办妥以下安排。表中已占按两人如期履职列示。

| 业务期间 | 常规定编 | 指定补招的交接名额 | 新人到岗前预留的来源 | 如期履职后的实际已占 |
| --- | ---: | ---: | --- | --- |
| 至 2027-03-21 | 1 | 0 | 此段无需预留 | 1，原主管 |
| 2027-03-22 至 2027-03-31，含首尾 | 1 | 1 | 交接名额 1 | 2，原主管占常规、接任者占交接 |
| 自 2027-04-01 起 | 1 | 0 | 原主管离任后腾出的常规名额 1 | 1，接任者占常规 |

交接期限取本次安排的起止日。办理权限须覆盖该岗和该次接替。每份接替同一天最多用 1 编，同一被接替任职同一天只对应一份安排，招聘和内部接任一并核对。招聘预留转为任职时沿用原交接记录。拟延期由有权人在原安排上更新日期并重验新增期间。

一次保存同时落实交接段和后续任期的常规名额。用量未知、任一段不足、经办人缺少相应权限，或新增期间遇到暂停补员，整笔保留原安排。交接截止日次日起专用额度自然到期，独立的常规增减编照其生效日执行。后来的增编也不自动改写此前采用的来源。

<a id="m03-br-036"></a>
### 4.4 M03-BR-036 改期、取消与已发生的履职事实

| 变动 | 有权人办理与结果 |
| --- | --- |
| 原员工提前离任或拟延期、留任 | 人事从原离任记录调整。提前离任时，同笔缩短专用期间，并从空出的日期起把接替者转回常规。延期时可一并更新交接截止日，或落实改期、调编。留任且无确定结束日时须落实常规去向。任一段有缺口，保留原任职、预留和录用，向有权者指出日期及缺额 |
| 新人改期、放弃、换人或需求取消 | 招聘改期按新旧到岗日重算，仅释放缩短段。换人可沿用同一份额及仍符合条件的期间，旧候选绑定及入职交接失效。候选人放弃但继续招聘时保留仍需的预留，招聘可明确释放。取消补招或缩减一人时同笔结束该份未用预留和相应专用额度。已发生的占编由人事按实际任职维护 |
| 入职已办理，尚未生效时撤销 | 人事按[未来首次入职撤销规则](#m03-br-027)收回该次未来入职及占编，同笔结束其未使用的后续交接额度。继续补招时由招聘按原份额重新落实期间和名额，保留原预留历史 |
| 两人已实际并岗，超出原安排 | 人事从原任职更正实际履职日期。原定无缝接替而实际发生重叠时也按实际日期计入两人 |

员工已经到岗，满编或暂停期间也可据实补录或更正。具有事实更正权限的人事从入职入口补录首次到岗，有招聘来源的沿用原录用交接。已有工作关系下漏办派岗或记错日期时，从该员工的任职办理。人事核实实际岗位、开始日及已有的履职依据，有确定结束日时一并记录。一次保存形成相应的人事记录，按适用规则同时计入实际占编，保留核定数和他人已有的预留。岗位详情按日显示差额和影响期间。

实况办理须有截至核实当日已履职的依据，日期填在过去本身不足以证明到岗。沿用入职或任职的身份、资格、来源和后继检查。持续履职的同一任职从实际到岗日起计入，按其有效期间计算后续影响。未来新入职、拟调动或拟延期仍按名额和补员状态办理。实际终结后再聘走入职入口。

用量核齐后，按业务日和当时采用的来源计算。交接额度到期或原无专用额度时，两份占编任职均计入常规。常规已占超过核定数的部分为实际超编，常规已占加常规预留超过核定数的部分为承诺缺口。阻止会扩大缺口的新承诺，原范围内履约、减量和提前寻访可继续。有权人从原业务办理调编、交接调整、调岗或结束任职。差额自相应生效日重算，历史可按原版本还原，并查到更正或调整的依据与办理人。

<a id="m03-br-037"></a>
### 4.5 M03-BR-037 员工调动与两岗占编

人事从「人员 → 员工 → 工作关系 → 任职」选定调出任职、调入岗位、生效日及办理依据。表单带出原岗最后在岗日、新岗到岗日和两岗名额变化，可直接保存。按拟任期内的全部已知变更核验，调出和调入一笔生效。未来调动保存后，今天仍计原岗，从生效日起新岗的相应名额已被占用。

| 人员安排 | 原岗、新岗与人数口径 |
| --- | --- |
| 同部门换岗、跨部门平调或晋升换岗 | 普通无重叠调动，原岗占编到生效日前一日，从生效日按新岗规则占编。两边各占 1 时原岗释放 1、新岗取得 1。免占转占编时只在新岗取得 1，占编转免占时只在原岗释放 1。仅按职务任职的期间依有效职务、组织办理。同一员工在企业范围仍计 1 人 |
| 原岗晋级、调薪或更换主管 | 岗位及占编性质相同，沿用原占编。薪酬、职级和汇报关系分别按其办理依据维护 |
| 过渡期兼任两岗 | 同一单位内有正式任命时，按[内部兼岗](#m03-br-028)办理。两份任职均占编时是 1 人、2 份任职、占 2 编。若只协助移交资料，按任务办理。原岗保留占编期间仍须为原岗的下一位接替者落实名额 |
| 人员调走，或连岗划转 | 只调人时，两岗核定数各归原岗。整个岗位改隶部门时，按同一岗位身份和生效日把核定数计入新部门，旧日归属可查。涉及实际任职归属变化由人事据实办理。企业决定转移核定名额时，另按[岗位间调剂](#7-大陆企业控编粒度的建议)核清两岗使用 |
| 跨用人单位、借调或轮岗 | M04 按真实用工安排确定各段任职。原占编任职保留期间继续计数。原岗已释放且确定返岗日时，从返岗日起落实名额。仅有返岗意向时，原岗余量仍可用 |

需要占编的调入须逐段扣除已有占编和招聘预留。免占编的岗位任职仍核对岗位是否启用、是否允许新增调入及员工任职资格。即使部门合计尚有余量、人员总数相同，只要有一岗无法落实，原两岗安排及各自后继记录均保留。[调动与晋升流程](../../architecture/target/diagrams/f02-transfer.svg)

<a id="m03-br-038"></a>
### 4.6 M03-BR-038 调出补缺与内部接任

原岗是否补人由调出部门决定。只有调动意向时，部门即可提出补缺，招聘可发布需求、寻访及面试。依赖原岗释放的正式预留，要等人事确定该员工最后占用原岗的日期。新岗接替已有员工时，人事可在调动中直接选择被接替任职，同时安排限期交接和交接后的常规占编。纯内部接任以调动动作及接任任职为依据。人事可在同一笔办理中确定未来离岗与到岗日期，无须另建招聘需求或录用单。

各岗按[同一接替规则](#m03-br-035)落实交接和后续名额。若内部接任者已绑定招聘份额，按[原招聘交接](#m03-br-027)核实本人、有效录用、岗位及任期，在原工作关系内办理调动并等额转换。其后从入职或调动入口重送，只能查回这一次转换。

销售岗和运营岗各核定 1 人，三人均占编。小林从销售调往运营，生效日为 2027-04-01。小陈经招聘接替销售，2027-03-25 到岗。运营原任小周最后在岗日为 2027-04-10。小陈的依据是招聘份额，小林接任小周的依据是人事调动。两人均如期到岗时，按下表核对。

| 业务期间（含首尾） | 销售岗实际任职 | 运营岗实际任职 | 专用名额与后续常规去向 |
| --- | --- | --- | --- |
| 至 2027-03-24 | 小林 1 人 | 小周 1 人 | 各用常规 1 |
| 2027-03-25 至 2027-03-31 | 小林、小陈 2 人 | 小周 1 人 | 销售交接 1 编、7 天。小陈从 2027-04-01 起接用销售常规名额 |
| 2027-04-01 至 2027-04-10 | 小陈 1 人 | 小周、小林 2 人 | 运营交接 1 编、10 天。小林从 2027-04-11 起接用运营常规名额 |
| 自 2027-04-11 起 | 小陈 1 人 | 小林 1 人 | 各用常规 1，两份交接额度均已到期 |

如果小林在运营如期到岗，同时有正式任命兼任销售至 2027-04-03，有权人可在该次办理中把销售交接延至当天。销售原任职结束日和小陈转入常规的日期随之调整。三天内销售、运营各有 2 份占编任职，各用 1 个交接名额，公司去重为 3 人。若小林只协助移交资料，销售仅计小陈 1 份任职。

<a id="m03-br-039"></a>
### 4.7 M03-BR-039 调动改期、撤销与同日对调

人事从原调动记录直接改期或撤销。Go 按新日程核验两岗受影响的任职、交接、预留、已发录用及后续调动。可办理时直接保存并显示两岗结果，明细按权限查看。需协调时只提示实际冲突和可处理的原单。缺编时指出岗位、首个缺额期间及人数。撤销须落实原岗恢复期间与调入岗后续安排。已承诺给接替者的名额，由有权人安排交接延期、调编或与候选人商定改期。原录用、第三人任职及后继动作按各自依据变更。已转换预留的调入还须按候选人确认的结果处理待履行录用。撤销成功时同笔结束该次未来占编及闲置交接额度，保留原转换历史。继续补招由招聘在原份额上重新预留。

已生效且确已履职的调动，按真实日期办理下一次调动。记录有误时按两岗各自实际到岗、离岗及任职依据更正，保留旧来源。在原岗继续履职的证据仅用于该岗，另一岗到岗情况须另行核实。

以上例把小林的调动推迟至 2027-04-04，小陈、小周日期不变。销售原交接到 2027-03-31，现缺 2027-04-01 至 2027-04-03 每天 1 编。有权者可同步把销售交接延至 2027-04-03。保存后销售交接由 7 天变 10 天，运营由 10 天变 7 天，各岗分别核算。若撤销调动会占去已承诺给小陈的唯一常规名额，则须先落实其长期去向。

两名员工同日互换满编岗位时，人事在“同日对调”选两份原任职和生效日，表单带出互换去向，一次保存。按交换后的结果逐岗逐段核对，计入其他人的占编、预留、未来交接和调动。两岗各核 1、两人各占 1 且资格完整时，交换后各占 1。任一岗不足、停用或暂停新增调入，或任何一方的资格、权限不足，整组保留原安排。改期和撤销同样检查双方及其后继，两份人事动作和原先的去向可查。

## 5 正常入口与应用合同

单个岗位从「设置 → 职务配置 → 岗位 → 岗位编制」办理，复用岗位的查找、记录导航和返回位置。岗位定义与核编分别授权，按所选额度记录维护，原件按准确来源只读。普通维护由服务端取北京时间今日，首次核定在未来时显示首条及尚未生效提示；用户明确选择的记录缺失时提示重新选择。保存定位本次结果，取消返回原岗位和原记录。

「部门编制分配」提供跨岗位的部门编制统计和多岗调剂。HR 按统计日期查看当日直属启用岗位的核定合计、未核编岗位数及有权查看的部门总额和待分配数。岗位范围授权仅披露可见小计；无岗位的获权部门也可办理。统计行有当日额度记录时按其身份下钻到同一岗位编制页；当日尚无记录时，统计保留“未核编”，打开岗位后可办理首次核定或查看将来的安排。返回统计时恢复日期和筛选。仅有编制权的人员从此进入，无须岗位定义读写权。统计日期、办理生效日、准确来源分别定位整体分配、额度变更和历史原件。普通岗位列表和详情不接受查看日期。核编／调剂的保存或取消、按日查看准确原件并返回统计是原生 200% 的代表流程，按本次变更选取。原生 400% 按共享规范触发专项。[当前维护与专项查询](../../adr/123-current-maintenance-and-dated-query-boundary.md) · [共享体验](../m02/012-m02-functional-and-interaction-design.md#m02-ui-expression) · [视口验收](../m02/012-m02-functional-and-interaction-design.md#m02-ui-viewport-matrix) · [对象接入矩阵](../m02/121-dated-object-admission-matrix.md)

| 首批操作 | 输入与结果 |
| --- | --- |
| 查当日、指定日、历史、原件 | 返回当前获权字段、核编状态、有效段和来源。指定不存在的来源返回 404 |
| 核编与调编（ChangeStaffingQuota） | 企业内部门或岗位、动作、日期、原因和目标定额。同一部门多行调整共用提交号，可含部门总额，只提交改变的目标及所读来源。更正、移日或删除附目标记录和预期修订。所有改动一起生效，各对象可查同次调整前后的原件。无变化返回原状态。非法数值返回 400，缺任一所需写权返回 403，超额、期间或版本冲突返回 409 |
| 查回原提交 | 响应丢失时，原经办人从「查看保存结果」按原提交号查回，结果及原件按当前权限展示。00028 前后的核编统一使用 `POST /api/v1/staffing-quotas/submissions/{id}/resolve`。已撤下按岗位 ID 提交的旧地址。现行写入口同号异载荷冲突。[可靠保存与查回](308-job-foundation-contract.md#m03-br-010) |

M03 维护部门与岗位额度、补员状态及用量校验，按日从两类原件计算岗位台账。M05 写招聘预留、释放和转换，保存录用版本及分段采用。M04 写任职及按期实际占编，保存任职版本和所用规则。经录用入职时，在同一岗位守卫和事务内，M05 转换该接受版本对应的预留，M04 写本次任职和占编。失败时两方一并回滚，重送按提交号查回原结果。M03 台账可追溯两域的来源。[上下文登记与各批验收范围](../../architecture/contexts.json)

仅更正需求说明时，编制消费方在原处理结果留下[无影响依据](../../architecture/target/10-ddd-and-state-contracts.md#62-消费者影响案与闭环)。若[员工历程](../../architecture/target/modules/m20.md)跟踪入职，任职有效或明确撤销时自动更新步骤，保留原完成证据。资料不足、相互矛盾或步骤确需人判断时才产生复核待办。

招聘在需求明细选择提前预留的期间。缩招或取消需求时，随单释放的名额引用该次决定及原因。需求仍继续而独立提前释放时，记录释放日和新的原因。份额、身份和来源版本由入口带入。编制管理员在岗位明细暂停或恢复补员，保存时核对所读状态。

招聘需求详情显示计划到岗日和各段名额，正式录用显示确认的到岗日。交接时可按岗位和日期查看常规数、专用数、实际已占及差额。取消草稿保留原安排。发生冲突时，向有权者指出首个缺额期间、人数和可办动作。资料受限时，只提示需有权人核实。详情、小计、导出和查回均保护可反推受限信息的数值。

## 7 大陆企业控编粒度的建议

首批支持部门独立定总额、岗位独立定额和从部门总额划给岗位三种实际制度。总额 10、开发 6、测试 3 时仍有 1 编待分配。同日将两岗改为 5、5 后，部门总额仍为 10。部门只作汇总时，岗位同样可以直接维护。见[同日调剂](#m03-br-040)与[后台验收](#m03-ac-131)。

若制度是“实际用人合计最多 10 人，开发最多 8 人、测试最多 5 人”，两个岗位上限可以重叠，这需要按招聘或任职事实扣减共享名额。该制度随实际用量另行立项。后台的待分配数只说明还有多少部门额度尚未划给岗位。[国内企业案例与边界](../../verification/313-staffing-establishment-review.md)
