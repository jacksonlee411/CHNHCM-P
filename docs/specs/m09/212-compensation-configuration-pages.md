# CHNHCM-212 薪酬配置后台页面与交互设计

从「设置 → 薪酬配置」分别打开「薪酬计划」或「职级薪酬标准」。使用离线原型可以从专业和运营两份月薪计划打开同一 P5 薪带，再对照管理年薪计划的独立标准。原型采用固定的合成页面状态。生产表单、权限和写入结果按业务方案实现。[离线桌面原型](prototype/compensation-configuration.html) · [业务方案](211-compensation-configuration.md) · [实施路线图](../../archive/plans/210-compensation-configuration-roadmap.md) · [登记表](../../governance/registry.json)

## 1 两个入口与返回路线

薪酬管理员按获授的计划管理或薪标管理权限从以下入口办理。新建、调整和更正时点击一次「保存」，启停、撤去时确认对应动作。成功后直接显示实际办理的记录及其生效日。提前保存的记录标示「尚未生效」，到日自动适用，无需另点「发布」或送审。原型日志中的「制度经办人」是该样例实际办理维护的管理员。[项目实施规范](../../adr/213-administrator-maintenance-and-effectivity.md)

| 角色要办的事 | 入口、选择与目的地 |
| --- | --- |
| 比较制度 | 薪酬计划列表 → 专业人员月薪计划或管理人员年薪计划 → 基本资料中的适用对象和组成。按计划编码、名称搜索。 |
| 从十月起调整本计划的固定津贴 | 薪酬计划 → 专业人员月薪计划 → 新增记录 → 带入完整组成，将岗位津贴从 300 调为 350 元/月 → 保存。日期轴分别查看九月适用的原额和十月新额。仅当原制度抄错时使用「更正记录」。 |
| 追一项金额的出处 | 计划 → 组成项「基本工资」→ 打开查看业务日适用的职级标准。普通详情用服务端今日，选定过去或未来记录时用所查业务日。例如十月计划采用七月月标。另从「保存时依据」打开当时采用的确切修订。返回原计划保留所选记录、组成项、滚动及焦点，返回列表保留筛选和页码。 |
| 维护薪带或定额 | 职级薪酬标准列表 → 选中 P5 人民币月标或年标 → 时间轴 → 新增记录、更正、停用或重新启用。保存后定位办理的那条记录，未来记录有尚未生效提示。 |
| 核查历史版本 | 当前详情 → 变更日志 → 办理前后值或确切来源。只读历史有持续可见的历史提示，可返回日志原行或重新读取当前资料。权限收窄时按现权重建可读上下文。 |

普通列表按服务端今日展示每个对象一行。未来首条提示首次生效日，已有对象的未来调整在详情日期轴选择。查询草稿在应用后更新列表，详情后退重新读取原条件并定位对象。列表、详情、表单和变更日志均有独立的加载、空结果和局部读取失败状态。失败时可就地重试并保留仍有权读取的资料。[日常维护边界](../../adr/123-current-maintenance-and-dated-query-boundary.md) · [按日对象准入](../m02/121-dated-object-admission-matrix.md)

计划可按状态筛选，职级标准可组合币种、约定频率、标准形式和状态。桌面表头和「更多操作 → 列筛选…」打开同一面板，放大后仍可从「更多操作」进入。已应用条件显示在控制区，可逐项查看、调整或清除。面板取消回到原入口并保留搜索草稿。应用条件同时采用此刻输入的关键词并回到第一页。翻页、改每页条数和重试沿用已应用关键词。查询失败时显示本次错误；成功查询且没有匹配对象时显示空结果。[共享列表准入及查询草稿](../m02/012-m02-functional-and-interaction-design.md#m02-ui-list-admission)

## 3 列表、详情与表单

### 3.1 薪酬计划

列表主列为计划编码、名称、适用对象摘要、生效日期、状态。详情「基本资料」在同一记录下依次展示基本资料、适用对象、薪酬组成。具备历史权时另有「变更日志」。从详情进入维护时，控制区提供保存和取消，选择来源使用已有目录候选。

| 字段或字段组 | 输入、默认及失败反馈 |
| --- | --- |
| 计划编码、名称、说明 | 首次填写编码与名称，编码随后只读。名称及说明按字段授权维护。重复编码定位编码，失权即清理受限输入。 |
| 生效日期、办理分类 | 新建默认 `1900-01-01`，允许显式改日。新增或插入按所选位置带出合法日期，更正带入原分类及原值。日期按 `YYYY-MM-DD` 输入。必要的操作原因按服务端可办事项提供。 |
| 适用对象 | 必选企业通用或指定范围。选择后者直接呈现所用维度、允许与排除的对象和实际有效期间。编辑计划时核对范围依据，通用范围也需要明确选择。缺项或范围冲突定位相应选择。 |
| 组成 | 每行维护项编码、名称、性质、取值方式、币种、约定频率、单位与适用的舍入规则。添加、移除或重排可用键盘，行内编辑暂存在同一份计划。按职级定价的行可添加多组「职级及引用标准」。企业通用、仅有固定津贴时只填该组成行。 |
| 固定额、职级标准、目标比例 | 固定津贴在本计划行中填金额、币种和单位，随计划生效，仅作用于本计划。选择职级标准时逐个选择职级及对应标准，显示获权的职级、频率、有效期间。目标比例同时选择同计划的基准项和舍入方式。切换方式时提示真正会丢弃的已填值。环形引用、无覆盖区间及不匹配的单位均在相应行反馈。 |

从 PRO-M 或 OPS-M 打开 BASIC 均定位同一 P5 月标。「职级标准」取值行只选择标准，金额在标准页维护。从 MGT-Y 同名项打开的是 P5 年标。目标奖金行显示「基本工资年额 × 12.50%」，有权人可解释 22,500.00 元参考额。金额受限时同时裁剪能反推金额的比例基准、结果和历史差异。[配置对象](211-compensation-configuration.md#m09-br-001) · [精度及基准](211-compensation-configuration.md#m09-br-003)

比例基准从同一草稿已录入的其他组成项选取。改名、重排保留原选择，删除已选项后显示基准待补，可在同一草稿内处理。基准是连续薪带时显示制度公式，允许先保存配置。切换空白取值方式直接完成，放弃已填金额（含零）、标准或基准时才提示。只改计划名称时仅提交变动字段，未获权的金额不带回表单。[金额与字段权限](211-compensation-configuration.md#m09-br-007)

### 3.2 职级薪酬标准

列表主列为职级、币种、约定频率、标准形式、生效日期和状态。定额、下限、指导值和上限分别成列，便于比较或单独显隐。获权列中该标准未填写的值显示「—」。当前无权读取的金额从列、列设置和缩放摘要同时移除。职级选择引用 M03。标准中直接显示所选职级名称。详情突出「人民币元/月」或「人民币元/年」，用户切换时间轴记录时资料和可办动作跟随该记录。切入准确来源时显示只读历史短条。

| 字段或字段组 | 输入、默认及失败反馈 |
| --- | --- |
| 职级、币种、频率及单位 | 新建必填。币种和频率确定计量口径，查看和更正时保留身份。选择职级时显示日期适用性，保存前重验。若职级始于 2027 年而初始日仍为 1900 年，在生效日期旁说明起始日期供修改。 |
| 定额或薪带 | 只提供定额和连续薪带两种形式。定额显示一个金额框，薪带直接显示下限、可空的指导值、上限三个框。首期没有薪档选择或档额表。数额按同一币种和精度录入，右对齐并显示单位，空指导值保持未设。范围冲突定位最先可改的字段。 |
| 生效记录、启停与历史 | 日期、原因及更正带值沿用共享动作。当前普通列表按今日投影，已保存的未来新标准仍可在时间轴选中。记录时刻以北京时间显示到秒，确切来源可按权展开，保留原始时刻。 |

操作区别可用七月月标核对。「新增记录」给新制度一个生效日。「更正记录」将抄错的上限 16,500.00 改成 16,000.00，仍是原生效记录。「删除此记录」展示撤去未来调整后的影响，确认后恢复前段延续。停用可能影响计划引用时显示有权查看的日期和处置入口。[生效与历史](211-compensation-configuration.md#m09-br-005) · [动作规范](../m02/012-m02-functional-and-interaction-design.md#m02-ui-actions)

## 4 操作保护与独立预期

| 操作条件 | 页面应该发生什么 |
| --- | --- |
| 管理员保存当前或未来版本 | 当前记录按生效日展示。未来记录保存后立即定位，标示尚未生效，到日后采用。回执与日志指向实际管理员和变更，不产生审批任务。 |
| 未编辑、改后取消、离开已改草稿 | 打开更正带入原值。未改直接离开，真实修改有继续编辑或放弃入口。取消不产生新版本，返回原记录和焦点。 |
| 缺项、金额错误、引用失效 | 顶部反馈能定位具体字段或组成行，保留其余合法输入。原标准失效时提示适用期间并允许重选。 |
| 其他人先保存、提交时撤权 | 冲突提示重读再核对，保留仍有权读取的草稿。部分字段撤权时重新读取，保留仍可维护的输入。清除受限金额、差异和链接，旧响应不能恢复受限资料。只读人员的控制区仅出现可办动作。 |
| 结果未知或重复点击 | 正在提交时保护本次输入。响应丢失后沿原提交号查回。先确定原结果，再恢复适用的办理入口。 |
| 从列表进入，切原件、后退 | 保存定位实际新增或更正的记录。取消返回原选择。回列表恢复已应用的条件、页码和可见焦点。只读历史始终可以返回当前获权资料。 |

正式页面在 1440×900 的桌面 100% 下对照同构建职级页面。关键路径另在原生 200% 检查表单末项、错误、保存/取消、历史短条、滚轮及 Tab、Shift+Tab、Enter、Escape。[共享视口矩阵](../m02/012-m02-functional-and-interaction-design.md#m02-ui-viewport-matrix) · [历史与权限](../m02/012-m02-functional-and-interaction-design.md#m02-ui-history)
