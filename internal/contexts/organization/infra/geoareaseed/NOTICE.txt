Provider metadata is offline initialization evidence, not a public resource or
permission field. This package prepares input; it does not publish a directory,
write a database or fabricate historical adoption references.

Macau supplement: chnhcm-macau-20261119-v1. macau.json contains ten place
names transcribed as factual data from Macau Post's standard postal address
format (three regions) and the government Cadastre Information System (seven
parishes). Each source entry contains the official URL and SHA-256 of the
retrieved page. The spelling is the provider's traditional Chinese. Entry keys
are CHNHCM identifiers. Neither source supplies an official code or a parent
relationship between these two sets. Page layout and maps are not redistributed.
The G0 source archive and published CN/HK/TW package remain independently pinned.
